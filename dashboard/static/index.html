모의투자 운영 대시보드

아직 갱신되지 않음
모의투자 전용 실전투자는 비활성화되어 있으며, 대시보드는 로컬 읽기 전용입니다.
빠른 시작사용 방법처음 실행부터 연구 평가까지 순서대로 안내합니다. 로컬 전용열기닫기⌄
  1. 모의투자 시스템 시작

    저장소 루트에서 실행하세요. 새로운 상태 폴더를 만들 때만 초기화합니다.

    python cli.py init --state-dir state
    python cli.py set-mode --state-dir state --mode paper
    python cli.py dashboard-refresh --state-dir state --env-file .env
    python cli.py dashboard --state-dir state --env-file .env --host 127.0.0.1 --port 8080
  2. Codex Desktop 연결

    Codex Desktop의 MCP 설정에 .codex/config.toml.example을 등록하세요. 연구와 평가 도구만 제공합니다.

    python -m integrations.codex_mcp_server --state-dir state --project-root .
  3. 연구 요청과 평가 실행

    Codex Desktop에서 대시보드와 연구 문맥을 확인하고, 검증된 연구 의도를 제출한 뒤 승인된 로컬 평가를 실행합니다.

    python cli.py research-intent --state-dir state --env-file .env --project-root .

안전 안내: 이 시스템은 모의투자 전용이며 주문 도구를 제공하지 않습니다. KIS 키는 Codex 프롬프트에 붙여 넣지 말고 무시 처리된 .env 파일에만 보관하세요.
