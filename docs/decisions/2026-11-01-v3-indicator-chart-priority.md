# ADR — Quant V3 지표 확장·차트 통합 우선 완료 (2026-11-01)

- **사용자 승인:** 2026-11-01 대화에서 "Quant 에서 Quant 지표 확장·차트 통합를 우선 마무리하자"를 명시. 기존 V05/T4 마무리 전에 지표·차트 통합 개발과 확인을 우선한다.
- **적용 질문:** 원본 20문답 Q05/Q09/Q10/Q11/Q12/Q16/Q18/Q20. 지표는 알고리즘 구성 요소이지 독립 투자 성과의 입증이 아니다.
- **현재 범위:** 기존 V3 Chart A15와 Strategy Track1의 실제 공통 계보(코드 487개의 기본 지표, chart opt-in 44개의 합 531개)를 통합 화면에서 재현하고, 이미 검증된 개발 QQQ P9 48실행 원장 중 G94의 1,508봉을 사용하여 패턴 오버레이와 대시보드 조회의 읽기 전용 종단 간 검증을 수행한다.
- **변경하지 않는 조건:** 원본 20문답, 연구 단계별 성공 기준, 소스 데이터/비용/평가/검증 보호 경계, 이전 300세대 원장·해시·부모, 고정 Moon/Quant MCP URL·OAuth, 실주문 OFF, 독립 봉인 OOS, Star, 현재 운영 main 및 실행 프로세스.
- **원래 상위 제품 게이트는 유지:** 지표·차트 하위 기능만 우선 정리하되 V05/T4 독립 검증, 외부 PIT/OOS, V06/V07의 GO/NO-GO 조건을 통과 처리하거나 삭제하지 않는다.
- **수락 조건:** (1) 출처가 같은 카탈로그 합계의 재현 및 opt-in 불변, (2) 실제 P9 원본 개발 봉과 원본 검증 증거만 수용, (3) 2026 봉인 OOS/실거래 접근 없이 코드+원장 동일 해시, (4) 연관 테스트·정적 검사 결과와 미해결 formal release 게이트를 명시, (5) 격리 브랜치에 커밋하고 검토 전 main 병합·배포는 하지 않는다.
- **이번 범위 밖:** 26개 특수 입력 미지원 지표 즉시 사용 승인, 487개의 전부 수식 수치 동치, 실제 모델의 전략 생성·체결·순이익 개선, 실운영 대시보드 배포 및 거래 허용. 미완료로 명시한다.
