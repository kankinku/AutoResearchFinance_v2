## 1. 변경 불가 상위 목표

**개별 QQQ 투자전략 수동 최적화가 아닌, 매 세대 스스로 알고리즘을 생성·백테스트·분석·개선하는 완전 자율 금융 연구 엔진.**

- *Indicator와 Algorithm 구분:* 연구/오픈소스/논문에서 확보한 지표는 구성요소. 여러 지표의 조합, 조건 분기, 시장 상황별 전환, 가중치, 진입·청산·위험 정책을 지닌 알고리즘이 진화의 대상이다.
- *세대의 완결 조건:* 알고리즘 후보 생성 → typed 검증/StrategyIR → 체결 추적 가능한 백테스트 → 비용·위험·손익 자동 계측 → 실제 LLM의 원인 **가설** → 후속 통제 실험/다음 세대 계획 → 증거 원장 커밋까지 완료해야 **1세대**다. 백테스트 횟수, mock 테스트, 계획 제출만으로 세대 성과를 부풀리지 않는다.
- *연구 진화:* 초기 랜덤 탐색과 성과/증거를 토대로 한 우수 후보 진화 및 LLM 가설 검증을 같이 실행. 중복 탐지·실패 기억·원인 반증·동일 예산 무작위 대조를 포함한다. 단일 고정 수익률 커트오프가 유망한 국면별 전략을 모두 폐기해서는 안 된다.
- *연구 증거:* 각 거래의 ID·당시 지표값·판단·비용·PnL·실패 이유와 변경 전후 대조를 기록한다. 관측 결과와 LLM 원인 가설을 별도로 표시한다.
- *운영 형태:* 지정 N세대 실행 **및** 중지 시까지 지속 실행, 오류 중단/재개/예산 상한/보고 요약. **후속 승인된 정책**인 기존 ChatGPT↔MCP 기본, 기존 URL·OAuth 유지, Paper-only·실주문 비활성은 유지한다. 이는 20문답 원문에서 사용자가 직접 확정한 세부라고 거꾸로 주장하지 않는다.
- *3단계 독립 성공 기준:* **1차 실제 자율 엔진 완성 → 2차 LLM의 원인 분석/진화 효과 검증 → 3차 유망 시장/다자산에서 거래 가능한 예상 순수익 발견·독립 검증.** 각 단계의 통과 조건을 혼동하지 않는다. 연구 코드 PASS·MCP READY ≠ 실제 GPT 100세대 ≠ 수익성 입증.
- *보안·안전:* GPT는 typed 연구계획을 제출한다. LLM/후보 코드는 protected data/backtest/costs/evaluator/validation/integrity, 봉인 OOS, 인증/주문 상태를 임의 수정하지 못한다. 실거래는 승인되지 않았다. 초기 고정 기간 QQQ는 기준 실험일 뿐 연구 범위의 영구적 한계가 아니다.

1. 시작 전에 `작업 ID / 대응 Q01~Q20 / 직접 해결할 사용자 가치 / 구현 경계 / 테스트·수락 조건 / 다음 고정 작업 / 금지사항`을 확인한다. 원본 인터뷰와 현재 구현을 먼저 읽고, 불필요한 신규 기능을 만들지 않는다.
2. 고정 단계/원본 20문답의 **필수 종속성** 범위 안에서만 별도 승인 없이 실행한다. 기능 수행의 상태·BLOCKED 사유를 갱신하는 것은 목표 수정이 아니다.
3. 아래는 **변경 제안만 가능하고 사용자 명시 승인 전 구현·배포하지 않음**: 새로운 최상위 목표, Q 항목 누락·축소, V05→T4 등 순서 재배치, 개별 전략 수동 재튜닝으로 우선순위 이동, 기본 MCP를 외부 모델 API 방식으로 교체, 자산/거래 권한 무단 확대, OOS/평가기준 보호 완화, 비용·성능 통과 커트오프 약화.
4. 원래 인터뷰에 없는 고정 티커·기간·실험 상한·모델 ID·거래비용 함수·합격점·벤더·라이선스·실거래 권한은 **IMPLEMENTATION_CHOICE/UNDECIDED**. 사용자 원래 결정이라고 주장하지 않으며, 변경 시 범위/비용/증빙을 별도로 기록한다.
5. 작업 완료 시 **Q 요구 해결의 전진**과 **실제 GPT 자율 루프 진행 상황**을 같이 기록한다. 또 다른 검증 도구를 추가하는 작업이 핵심 자율 연구 검증을 지연하면 `SCOPE_DRIFT` 위험으로 검토한다. 단순 코드 테스트로 경제성/연구 자율성을 증명했다고 서술 금지.
