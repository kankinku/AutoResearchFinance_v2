# 결정 — V05와 T4만 우선 실행, 나머지 V단계 보류

- 결정일: 2026-10-29 KST
- 승인 근거: 사용자 현재 지시 "V단계는 아직 진행할 생각이 없어서 (V05만 해보자) 1,2번 우선순위 진행해줘."
- 원본 계약: [2026-10-14 20문답](2026-10-14-autoresearch-interview-20q.md), [2026-10-16 범위 잠금](2026-10-16-autoresearch-20q-scope-lock-v1.md).
- 이번 결정은 **현재 실행할 작업을 V05 → T4로 한정**한다는 뜻이다. V01~V04, V06, V07은 **DEFERRED_BY_USER**이며 수행하지 않는다. 기존 20문답의 최종 목적에서 영구 삭제/취소한 것이 아니므로 재개 시 별도 확인 후 실행한다.
- V05: 기존 비용·슬리피지·일봉 거래량 참여율·개발구간 다중검정 진단에 대한 구체적 결함 수정 및 검증. 주문·시장가격·원본 비용정책을 변경하지 않는다. 이 단계에서 직접 실행가능한 거래 용량이나 순수익 인증은 불가.
- T4: 기존 인증된 ChatGPT↔Quant MCP와 원래 연구원장을 유지하며 매 세대 가설·실제 백테스트·GPT 진단·S7 대조·다음 계획의 증거와 세대 누적성을 조사하고 실증한다. `get_research_batch_status`의 고정 ResearchIntent 배치는 모델 연구세대로 세지 않는다.
- 개발 데이터에 대한 비PIT 연구만 허용하며 2026 봉인 OOS·PIT/V01~V04 외부 데이터 확보, 주문/페이퍼 실시간 실행 V06, 전체 GO/NO-GO V07은 모두 미실행.
- GPT 독립 공급자 호출/무인 컨트롤러의 출처 증빙이 없는 경우 채팅 주도형 완료와 완전자율성을 구분한다.
- main·기존 고정 MCP URL/OAuth/연구 원장·보호 백테스트 코어·실주문 비활성을 그대로 유지한다.

**현재 개발 순서:** V05의 현존 결함/수락 → T4 증거 회수·기본 연결 상태 검증 → 필요할 때 실제 GPT 10→100 반복의 안전 게이트. 그 외 V 단계는 새 사용자 지시 전 착수하지 않는다.
