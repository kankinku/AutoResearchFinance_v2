# Quant — 과거 실험 제외 및 신규 연구 초기화 승인

**상태:** 사용자 승인(2026-11-10) · **범위:** 연구 세션의 새 출발점 · **기존 목표·안전 경계 불변**

## 사용자 결정

2026-11-10 지시: "기존 150세대등 기존의 실험은 제거하고 설계대로 Quant시스템 개선 작업 진행해줘."

**적용:** 기존 G1~G150과 과거 실험 성과, 부모 계보, S7 대조, S8 기억 및 후보 승격을 앞으로 진행할 Quant 연구의 **활성 상태에서 제외**한다. 다음 연구는 신규 세션, 신규 평가기 버전, G1부터 시작한다. 이전 실험을 새 세대의 점수·기준선·부모·탐색 정책 입력으로 재사용하지 않는다.

## 기존 설계와의 차이

- 구 G150 원본의 복구 및 연장은 신규 연구의 선행 조건이 아니다.
- 원본 20문답(Q01~Q20), StrategyIR, V05→T4→V01~V04→V06→V07, PIT/OOS, 주문 금지, 32개 MCP 및 OAuth 정책은 변경하지 않는다.
- Git의 과거 연구 보고서는 활성 연구 입력이 아닌 역사적 개발 기록으로만 둔다. Git history를 덮어쓰거나 원장·태그를 위조하지 않는다.
- 신규 세션은 **새 빈 상태 경로**에서 시작하며 구 SQLite/로그/원장에 이어붙이지 않는다. 발견되지 않은 운영 파일을 지우는 초기화 코드는 추가하지 않는다.

## 현재 실측과 제거 범위

- Git이 추적하는 state/champion.json, state/frontier.json, state/knowledge.json, state/rescue_pool.json은 빈 상태로 확인. 해당 활성 파일에 삭제할 과거 세대 0건.
- 현재 확인한 /shared의 Quant 디렉터리와 격리 worktree에서 과거 cycles.sqlite, gateway.sqlite, QQQ Parquet을 찾지 못했다. **물리 삭제 NOT_RUN**. 데이터가 사라졌다는 단정 금지.
- docs/operations의 과거 실험 감사 문서와 표는 추적용 역사 자료이며 새 학습/부모 선정에는 사용하지 않는다.
- 향후 실제 운영 데이터 발견 시 파일/서비스/세션 소유권과 진행 중인 세션을 확인한 뒤 **해당 연구 결과만** 대상으로 안전하게 제거한다. 시장 원본, OOS 검증 자료, 코드, 인증, 주문, 시스템 설정은 제거 대상이 아니다.

## 신규 연구 수락 기준

1. 신규 연구 session_id는 과거 14626d55fb2b461faa485df911920071과 달라야 하며 G1부터 시작한다.
2. 신규 부모/champion/S7/S8에 구 세대 혹은 이전 실험 데이터가 유입되지 않음을 테스트한다.
3. 수정된 계산 엔진과 새 평가 버전/데이터 정책 해시를 사용한다. 옛 G150 무결성 재검증은 새 연구 선행조건에서 제외한다.
4. 실제 시세/공정 대조/OOS 자료가 없으면 해당 실험은 BLOCKED. DB 부재를 이유로 독립 가능한 코드 개선을 중단하지 않는다.
5. 활성 연구에서 배제됨과 원본 물리 삭제됨을 구별하여 정직하게 보고한다.

## 승인 근거

기존 상위 계약은 docs/decisions/2026-10-14-autoresearch-interview-20q.md 및 docs/decisions/2026-10-16-autoresearch-20q-scope-lock-v1.md. 본 ADR은 2026-11-10 사용자 명시 요청으로 기존 150세대 등 과거 실험의 **신규 연구 계승 중단**을 확정하며, 보고서 삭제/운영 서비스 무단 중단/실거래 권한 변경으로 확대하지 않는다.
