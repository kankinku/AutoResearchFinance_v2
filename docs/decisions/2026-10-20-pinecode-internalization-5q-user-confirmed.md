# ADR — PineCode 원리 추출·원본 재현·GPT 연구 내재화 (5문답 확정)

## 1. 직접 확정한 다섯 답변 (원문 의미)

| 번호 | 선택 | 확정 요건 |
|---|---|---|
| 1 | **C** | 원본 Pine 지표/전략의 **핵심 원리를 독립 기능으로 추출**하고, **원본 전략도 재현**하여 비교 기준으로 보존 |
| 2 | **C** | GPT에게 지표 조합뿐 아니라 **내부 수식·조건·상태기계 수정과 완전히 새로운 알고리즘 창안**을 허용 |
| 3 | **C** | GPT가 **원본 전략을 부모로 계승·변형**하거나 **서로 다른 원본의 원리를 재조합**하여 새 알고리즘을 만들 수 있도록 두 경로 모두 허용 |
| 4 | **B** | 미지원 Pine 기능은 별도 **격리 구현→원본 의미론·안전 검증→범용 엔진 기능으로 통합**. 현재 엔진에 맞게 조용히 생략/변형하지 않음 |
| 5 | **B** | **정식 내재화 완료는 GPT가 실제 자율 연구에서 선택·수정·S7 실험·결과 분석·다음 세대에 활용할 때만** 인정 |

**목표는 Pine 인터프리터를 붙이는 것이 아니라 Python 계산 기능, 검증된 typed feature, StrategyIR/계산식/상태기계/체결 계약으로 구조를 재설계하는 것.** 원본 실행기 의존을 최종 런타임의 필요 조건으로 만들지 않는다.

## 2. 단일 원본 당 P1~P7 작업 단계 및 수락 조건

| ID | 작업 | 수락 증거/분리해야 할 사실 |
|---|---|---|
| P1 | 소스 취득·신원·버전·라이선스·SHA·상세 기능 인벤토리 | 원본 URL/업로드 해시·출처·허가 상태; 저작권 유보/NC/미확인 코드는 허가 없이 직수입 금지 |
| P2 | 원본 지표 계산 및 실제 전략이 있으면 주문·수량·리스크·세션을 **원형 의미론**으로 격리 재현 | indicator()는 신호/표시; strategy()만 원본 거래 비교. 미지원 수단은 UNSUPPORTED로 표시 |
| P3 | 공통 수식·조건·상태·risk policy를 작은 재사용 기능으로 분리 | source-derived feature IDs, 입력 단위·warmup·결측·시간 정렬·동등/변형 파라미터와 provenance |
| P4 | 필요한 미지원 기능을 격리 실행 검증 후 안전한 범용 엔진 인터페이스로 추가 | 보호된 core 변경 금지, 별도 승인/회귀 필요, LLM 임의 코드 실행 금지 |
| P5 | 원본과 bar-level series, 신호 시점, 상태 전이 및 전략이면 fill·거래비용·position·PnL 비교 | TradingView 브로커 모델의 OHLC path/스톱/갭/슬리피지 차이를 설명/검증; PIT/미래참조/재현성 검증. 이 단계를 안 거치면 원형 파리티 주장 금지 |
| P6 | 통과 기능만 opt-in 연구 카탈로그/typed StrategyIR 또는 독립 feature compiler 연결 | GPT-visible 실제 callable contract, licensing/provenance/evidence, 실패 시 fail-closed. 연구 계획문맥 **설명 목록만 노출 = 미등록** |
| P7 | GPT/MCP 실제 세대 연구가 원본 부모 변형 또는 원리 교차 조합을 **선택→제출→typed 검증→비용 반영 S7→실제 LLM 진단·다음 계획·연구 기억/계승**에 사용 | GPT 단독 동작 및 재현 가능한 S7 실거래가 아닌 백테스트 감사 해시; mock/정적 문서/단순 계산기 저장은 이식 완료 아님 |

**완료 정의:** P1~P7이 모두 확인된 원본만 `INTERNALIZED_GPT_RESEARCH_VERIFIED`; P2/P3 일부는 `SEMANTIC_PORT_STAGED`, P5 실패는 `PARITY_BLOCKED`. 투자 성과 개선은 *내재화 완료 조건이 아님*. 알파·일반화 가능성·예상 순수익은 독립 검증 별도 단계.

## 3. 원본 전략 보존 + 원리 추출의 양쪽 경로

- **Baseline lane:** 원본 Pine의 매매 의미론에 최대한 동등한 격리 StrategyIR/strategy baseline, 파라미터 고정, provenance hash·거래 원장. 원래 indicator()에 임의 매매를 부여하지 않음.
- **Composable lane:** 계산식·지표·상태 전이·조건식·리스크 정책을 독립 feature/typed operators로 제공하고 GPT가 병합/제거/가중·동적 분기·신수식을 자유 설계.
- 두 경로는 **동일 개발 데이터·비용·실험예산 S7 비교**를 공유하고 baseline은 후속 변형으로 덮어쓰지 않음. 원본 원인 분석·반례·세대 간 계승·원리 재사용으로 논리적 진화를 평가.

## 4. 기존 제품 범위와 안전성

본 결정은 [원본 20문답](2026-10-14-autoresearch-interview-20q.md) Q05~Q12와 [기존 잠금](2026-10-16-autoresearch-20q-scope-lock-v1.md)을 **구체화한 하위 워크스트림**이다. **상위 진행 순서 V05→T4→V01~V04→V06→V07는 변경하지 않는다.** GPT의 기본 연결은 기존 ChatGPT↔MCP; 기존 OAuth URL/공식 G350/검증 원장/보호된 backtest·data·evaluator·costs·integrity/봉인 OOS는 수정하지 않는다. 실거래 OFF 및 거래 권한 추가 없음. 새로운 수식은 허용하지만 검증 전 자동 체결이나 운영 등록은 허용하지 않는다. 라이선스 확인 안 된 원본을 소스 그대로 복사하거나 '내재화'라 주장하지 않는다.
