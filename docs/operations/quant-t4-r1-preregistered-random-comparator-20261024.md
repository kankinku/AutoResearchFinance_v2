# Quant AutoResearch — T4-R1 사전 고정 무작위 10후보 대조 실측

**기록일:** 2026-10-24 KST
**범위:** T4(S4/S5), Q02/Q06/Q07/Q08/Q09/Q17/Q20. 실제 GPT 연구 진화 효과에 대한 **공정 비교 근거 일부 확보**. V05→T4→V01~V04→V06→V07 순서·원본 20문답·protected core·운영 URL/OAuth/원장/봉인 OOS·주문 비활성은 변경하지 않았다.

## 구현 목적·한계

P4 실 GPT 작성 계획 10세대 성과가 처음부터 우수한 설계인지, 무작위 탐색과 비교해도 가치가 있는지를 설명한다. 결과에 맞춘 임의 시드 재탐색 방지 위해 **실제 대조군 전체 실행 전** 생성 규칙·시드·검사/유일성·유한 S7 예산을 커밋 `83d164b`로 GitHub에 별도 보존했다.

**중요:** 실제 GPT 10개는 8개 신규 AlgorithmPlan + 2개 감사된 계승 StrategyIR 세대이며 각 세대는 실제 GPT의 원인 진단을 포함한다. 무작위 **10후보는 10세대가 아니다**. 대조군은 계승 경로가 없는 독립적 AlgorithmPlan 10개와 각각의 고정 기계적 S7 연구 가설 1개이다. 따라서 **S2 후보 10개 + S7 시도 10개**라는 두 측정 예산만 맞춘 탐색 설명군이고, 연구 모델의 추론/비용/재시도/부모 계승/피드백 진화는 동등 비교하지 못한다. 모델 우수성의 인과 추정·통계적 유의성·P5 승격 판단에 쓰지 않는다.

## 사전 선언 대조 설계

- `research/llm/p4_random_candidate_control.py`: `Random(20261024)`, VERIFIED 신호만, 레짐/리스크 게이트와 binary entry 투표 1~2개, 1~2개 조건 분기, 비율 100%; 유일한 **의미상 전략계획** 10개를 값/수익률 관측 전에 뽑아 고정. 비정상적 계획도 성과와 무관하게 후보로 남긴다. 모든 신규 샘플의 전략 계획/유일성 hash, 체결/equity/원가/감사 hash 기록.
- 같은 계약 `academic-research-cost-v1`(기본 commission 1bp, spread 2bp, slippage 5bp), 다음 봉 시가, 동일 2020-01-02~2025-12-31 RAW QQQ DEVELOPMENT 데이터 1,508봉, 초기 1만 달러, OOS와 거래 주문 불허.
- 모든 후보에 **고정 70% 비중 축소 가설** 1번씩을 제출하여 S7 paired backtest 실행. 10/10 측정 성공했으며 모두 `DIRECTION_MATCHED_DEVELOPMENT_ONLY`였다. 이것은 비중 감소 시 MDD 감소하는 기계적 확인이므로 **LLM이 좋은 원인을 발견했다는 근거가 아니다**.
- `scripts/quant_p4_random_control_10slots.py`: 먼저 기존 `scripts/quant_p4_verify_10gen.py` 검증 및 original dataset SHA 일치 → 원본 검증된 catalog를 임시 SQLite로 read-only backup → 사전 등록 10후보 평가 → 원본 P4 재감사 SHA의 사전/사후 일치 확인. Git에는 raw 데이터/DB/credential·대화 원문 저장하지 않는다.
