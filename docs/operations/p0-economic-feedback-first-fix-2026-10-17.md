# Quant Autoresearch P0-1 — 대조 실험의 경제적 성과 피드백

## 기존 문제

- 133세대 S7 대조 실험에서 116건이 거래 횟수 변화 자체를 측정했다. 예측 방향이 맞으면 `EVOLVE`를 권고했으며, 같은 대조 전략의 최종 자본 손실 여부는 권고 판정에 반영하지 않았다.
- 대조 전략의 손익 개선 52건, 악화 80건, 변화 없음 1건. 거래 수 감소를 연구 성공으로 취급할 수 없음.
- 기존 `AlgorithmPlan`은 완성 전략 자식의 StrategyIR를 다음 세대에 자동 보존/승격하는 인터페이스가 아니다.

## 1차 구현 범위

- `research/llm/economic_feedback.py` 추가: 저장된 S7 레코드의 내용 해시, 원본 세대 및 가설 ID, 제안 자식 전략 해시, 개발 전용 보안 게이트, 부모 자본의 재현을 검증한 뒤 동일 자본·비용 모형의 실제 부모/자식 종말 자산을 비교.
- 요약에 부모 대비 수익률 증감(%p), 개발 결과 개선/악화/무변화 횟수, 실제 가설 측정 지표 종류, 자식 체결 수 및 추정 완료 거래 수, 네 개 **재사용 개발 구간**의 상대 낙폭 악화 횟수 반영.
- **30건 이상 완료 거래**를 보유하고 개발 수익률이 개선된 자식만 상위 5개 **사람/LLM 검토 후보**로 표시. 변경 명세(`proposed_intent`)와 증거 해시 동봉. 모든 후보에는 `NOT_ESTABLISHED`, OOS 미승인, 자동 승격 금지가 포함됨.
- `application/academic_checkpoint_service.py`의 외부 GPT 연구안 컨텍스트에 `economic_feedback`를 추가. 최신 실험이 예상 거래 수 감소 방향은 맞아도 **수익이 악화됐다면** `EVOLVE` 대신 `TEST_HYPOTHESIS`, 거래가 완전히 사라졌다면 `EXPLORE`, 변경 효과가 없으면 `EXPLORE`, 과도하게 소수 거래만 남았다면 `TEST_HYPOTHESIS`로 변경.
- `research_objective`로 `total_return`, `cagr`, `sharpe`, `max_drawdown`을 연구자가 다음 가설의 직접 측정 지표로 사용할 것을 안내. 기존 `trade_count` 방향 일치 = 수익성 승인 아님.
- **기존 제약 유지:** 주문 권한 없음, OOS 미승인, 기존 채점/거래 실행/지표/우회 URL·OAuth·MCP 32도구 명칭 변경 없음, 저장된 133세대 불변.

## 한계와 다음 순서

이 변경은 **P0-1 권고/피드백** 개선이며, 포지션 사이징·수익률 벤치마크·청산 규칙 표현·정식 자식 전략 승격 및 독립 OOS 판정은 아직 구현하지 않았다. 현재의 선정 큐도 과거 같은 표본의 선택 편향을 제거하지 못한다.

- P0-2: 독립 검증이 가능한 QQQ 동일 시점·수수료 및 현금 노출 조정 기준 계산.
- P0-3: 해시 검증된 자식 StrategyIR 재생/승격 가능한 명시적 전략 부모 인터페이스, 실패 원복 검증.
- P1: 진입 및 청산 규칙 독립 컨트롤, 0~100% 연속 위험 노출 정책, 새로운 학술 지표 및 시장 국면 제안/중복 제어.

## 배포 확인 지표

현재 활성 세션 `2ba41aaeacd547319cfbf7e6f266ad11`: 로컬 33/100(전역 133/300), 다음 전역 134세대. 기존 원장 S7 대조 33건 재현 시 개발 수익 개선 17·악화 16. 마지막 133세대의 대조는 **수익률 +37.57% → +31.39%**로 악화되어 새 연구 방향 `TEST_HYPOTHESIS / LATEST_MATCHED_CONTROL_LOWER_DEVELOPMENT_RETURN` 권고를 기대한다. 체크포인트 토큰과 원본 증거 해시는 변경하지 않는다.
