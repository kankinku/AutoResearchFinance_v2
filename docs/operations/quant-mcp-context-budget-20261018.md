# Quant MCP read-only context budget — 2026-10-18

- **Stage:** T4 operational dependency (Q02, Q06, Q08, Q16, Q17); not a new roadmap stage.
- **Objective:** Avoid ChatGPT conversation-limit failures caused by unbounded read-only MCP overview responses; keep immutable research memory in its existing state paths.
- **Scope:** `get_dashboard_status`, `get_research_brief`, `get_research_batch_report` only. Existing 32 tool names, OAuth/public URL, external ChatGPT MCP controller and `orders_enabled=false` unchanged. Plan, diagnosis, checkpoints, hashes, evidence writes, sealed OOS and orders are unchanged.
- **Implementation:** `integrations/mcp_context_budget.py` performs deterministic, server-side response-only projections once a read-only reply exceeds 24 KiB. Dashboard keeps live health/progress and recent entries; brief keeps champion, policy, research inputs and compact prior-research metadata. `response_mode=full` explicitly retrieves the full original overview. `_context_budget` declares original response size/digest and which record lists were shortened; no claims of verified OOS or a successful causal improvement are inferred from these summaries.
- **Observability:** Only tool name, UTC, size before/after and response mode are written to bounded local telemetry `state_dir/logs/mcp-context-metrics.jsonl` (mode 0600); no raw strategy, market data, OAuth tokens or input payload in metrics.
- **Read-only measured production-state fixtures:** `get_dashboard_status` 18,308,629 B → 17,838 B (99.90% smaller); `get_research_brief` 69,393 B → 15,834 B (77.18% smaller); `get_research_batch_status` 856 B unchanged. Test data and source research store were not modified during these measurements.
- **Safety:** The original source payload remains server-side, including all 3,823 dashboard tests/trend records. Full mode intentionally bypasses the transport budget and must not be used as a routine polling default. Excessive non-overview / critical checkpoint replies remain a follow-up risk; the transport budget does not control ChatGPT's own internal memory implementation.
