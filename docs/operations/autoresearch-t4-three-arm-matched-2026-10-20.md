# T4 — GPT·Random·Local 3군, 동일 표현 범위의 실측 비교

**2026-10-20 KST | 개발 데이터 한정 | 30/30 원본 평가 + 30/30 S7 | GPT 우월성 미입증**

## 1. 실험 설계와 사전 동결

대상은 기존 인증 Quant AutoResearch MCP의 AlgorithmPlan v1이며, 새 P1-3 범용 표현 언어의 운영 실험이 아니다. GPT가 이전에 직접 작성·평가한 10세대와, 동일한 전략 JSON 계약과 검증 지표 8종으로 만든 무작위 10개 및 로컬 10개를 비교했다.

- 세 군 모두 국면 지표 parkinson_variance/sma_direction, 진입 지표 dual_sma_trend_50, ema_direction_20, previous_range_breakout, range_low_reclaim_20, sma_pullback_20, time_series_momentum을 사용할 수 있다. 고정 100% 현금 long/flat, 동일 비용/다음 봉 시가 체결과 QQQ 2020-01-02~2025-12-31 RAW 개발 데이터(1,508봉)를 적용했다.
- 무작위·로컬 후보는 결과를 확인하기 **전에** seed 20261020으로 10개씩 생성해 사전 동결했다. 동결 SHA256: 63b2a84506443a76b86f691f84b01fe8361933d84bfaee18cf010a82d12538a1. 동결 후보와 생성기는 GitHub 커밋 bcba8ac에서 실제 실행 전에 Push했다. 검증 전용 후속 커밋 3b3eac6은 후보를 수정하지 않았다.
- 각 군 원본 전략 10회 비용 반영 백테스트와, 각 군 S7 후속 연구 10회를 기록했다. GPT 후속 가설은 모델이 거래 근거에 따라 선택했지만 무작위·로컬 후속은 이미 정한 단일 진입 점수 >0.99를 적용했다. 따라서 **원본 전략 비교만 1차 지표**이며 S7의 질을 동등하게 비교할 수 없다.
- 세션: GPT 30da9a29502d4bf2a67e014358dab2e9, Random 0818025b610442c591a0b1adfe8d25c6, Local 8ac7901305b64b819e40e3dbd27f2c24.
- 세 군의 계획은 동일한 지표·AlgorithmPlan 계약의 표현 범위에 속하지만 **후보 선택 확률분포와 적응 기회는 동등하지 않다**. GPT는 이미 개발 수익률/손실 피드백을 보며 작성한 사후군이고 무작위·로컬은 실측 전에 고정된 비적응군이다. 실제 LLM 토큰/벽시계시간도 같지 않다.
- 두 통제군의 계획은 GPT가 아이디어를 낸 것이 아니라 결정론적 코드가 생성했다. 이 대화의 ChatGPT가 운영 MCP에 제출했기 때문에 MCP 클라이언트 표시는 GPT인 것처럼 보일 수 있다. **제안자와 제출자를 구분**한다.

## 2. 사전등록 지표에 따른 결과

| 지표 | GPT 10개 | Random 10개 | Local 10개 |
|---|---:|---:|---:|
| **누적 수익률 중앙값 (1차)** | **+19.655%** | +4.233% | **+30.997%** |
| 누적 수익률 평균 | +23.583% | +11.285% | +28.650% |
| 전체 기간 MDD 중앙값 | 23.457% | 13.513% | 20.642% |
| Sharpe 중앙값 (유효 값만) | 0.323 (10개) | 0.353 (8개) | 0.420 (10개) |
| 시장 노출 중앙값 | 47.447% | **3.084%** | 49.237% |
| 청산 거래 중앙값 | 35회 | 20.5회 | 48회 |
| **사전 4조건 모두 통과** | **1/10** | **2/10** | **1/10** |
| 최고 개발 수익률 | +81.765% | +44.216% | +60.772% |
| 최저 개발 수익률 | −16.798% | −11.037% | +3.981% |
| 매매 전혀 없는 전략 | 0 | **2** | 0 |

사전 등록 필터는 총수익 >0, MDD ≤20%, 청산 거래 ≥10, Sharpe >0.5의 동시 만족이다. Random의 두 무거래 전략은 수익 0/MDD 0/Sharpe 결측으로 판정에서 제외하지 않고 실패로 센다. Random의 낮은 MDD 수치는 노출 중앙값 3.084%와 연결되어 있으므로 위험관리 우위로 해석하면 안 된다.

동일 QQQ RAW 개발 매수·보유의 참고 누적 수익률 약 +187.77%는 세 군의 최고 후보보다 높다. 세 군의 개발 원본 전략은 비용이 적용된 평가지만, 가격 시점 수정 이력 및 기업행위 PIT 검증이 없어 투자 미래 성과로 사용할 수 없다.

**판정:** 1차 지표인 중앙값 수익률은 Local > GPT > Random. GPT는 최고 수익 후보가 있지만 통합 기준 통과 수는 Random보다 낮다. 따라서 **GPT 우월성·통계적 유의성·인과·실전 수익성은 입증되지 않았다.**

## 4. 이번 결과로 확정하지 못한 것

이번 비교는 문법, 지표 목록, 연구 자료와 **전략 평가 횟수**만 맞췄다. GPT가 이전 결과를 참조한 적응형 작성 방식과 무작위·로컬의 결과 비적응 생성 방식에는 구조적 차이가 있으며 한 가지 랜덤 시드, 개발 시장 1개, 반복 테스트된 기간 1개밖에 없다. 실제 토큰 사용량·실행시간, 공정한 다중 시드 유의성 검정, 독립 PIT/OOS가 없는 만큼 GPT의 정책적 우위나 미래 알파를 판단하지 않는다.

서비스의 model_autonomy_verified=false / independent_profitability_verified=false 유지. 이 실험은 실제 연결된 MCP에서 이루어졌으나 P1-3 GeneralResearchPlan 및 StateMachine을 운영에 연결하거나 실거래 주문을 활성화한 것은 아니다. 기존 G350 연구 원장, 운영 인증/OAuth/기존 MCP 주소는 변경하지 않았다. 별도 Random·Local 연구 세션의 실측 증거만 추가되었다.
