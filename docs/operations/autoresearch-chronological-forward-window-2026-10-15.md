# P0 시간 경계 검증기 — 2026-10-15

## 범위와 이유

기존 QQQ 개발 샘플(2020~2025)의 과거 봉을 지표 계산에만 사용하고, 2026년 검증 구간의 **첫 완료 봉부터 신규 신호 생성**, 그 다음 봉 시가부터 체결 허용, 그 시점에서 투자금 1만 달러와 미보유 포지션으로 시작하는 순차 연구 평가기를 구현했다.

기존 2026년 콜드 스타트 방식은 짧은 데이터 구간 첫날에 가격 지표도 함께 초기화되어 신호가 크게 달라졌다. 이것이 새 검증 기간의 수익성을 실제보다 과소/과대평가할 수 있어 과거 데이터 워밍업과 평가 자산곡선을 구분했다.

## 코드 구조

- research/indicator_engine/strategy_adapter.py: `evaluate_compiled_development(..., signal_start_at=...)` 선택형 매개변수 추가. 기존 백테스트 엔진의 next-open 정책과 증거/데이터 해시 검사는 유지. 기존 호출은 변경 없이 동일하게 실행된다.
- research/indicator_engine/forward_window.py: 새로운 연구 전용 `evaluate_chronological_window(catalog, plan, historical, forward)`.
  - 원본 시계열 버전/심볼/1d 캘린더, DEVELOPMENT zone, 학습 마지막 봉이 검증 첫 봉보다 엄격하게 과거인지 확인.
  - 서로 다른 시세 공급자 또는 원시/조정 가격 정책을 연결하는 행위를 금지하며, 한쪽에만 provenance가 있는 혼합도 금지.
  - 과거 봉 최대 300개 사용(실제로는 검증 지표의 lookback보다 1개 이상 긴 기록 필요). 제공된 지표의 입력 값은 기존 VERIFIED 카탈로그에서만 수집.
  - 과거 구간의 신호는 만들어도 신규 거래를 허용하지 않음. 결과의 과거 구간 equity가 전부 initial_cash와 동일해야 통과.
  - 검증 **첫날 종가에 처음** 주문 신호를 생성하므로, 해당 첫날 시가/종가까지는 거래하지 않음. 다음 검증 거래일 시가부터 원래 Canonical BacktestEngine 정책으로 체결.
  - 결과 지표 계산 시 과거 warmup equity는 아예 제외하고 검증 첫날부터 별도 계산. 성과에는 해당 검증 구간의 체결 수수료·슬리피지 반영.
  - 체결 건수와 완료 왕복 거래를 구분하고, 아직 청산하지 않은 잔여 포지션은 평가액에 반영하되 완료 거래 수에는 포함하지 않음.
  - 원본 historical/forward 각각의 데이터 해시, 합친 입력의 hash 및 가설/전략 hash, 수익·최대낙폭·Sharpe, 순자산과 최초 체결일을 남김.
  - 가격 히스토리 원본/외부 검증 자료의 provenance를 새로 검증했다고 주장하지 않도록 합성 연산 데이터는 별도 신원으로 hash, research-only로 표시.
- 결과 `validation_decision = NOT_VALIDATED`, `point_in_time_independently_verified = false`, `candidate_promotable = false`, `broker_executable = false`로 고정. 단순 탐색 임계값 통과 가능 여부 `descriptive_gate_met`와 승격 여부를 분리했다.

원래 선택해 둔 세 계획을 **수정하지 않고**, Tiingo 원본 2020~2025 QQQ 학습 데이터의 마지막 300봉을 지표 워밍업으로만 사용했다. 2026년 검증 구간은 187봉.

- 모두 새 검증 첫날 순자산 정확히 1만 달러였고, **최초 체결은 2026-01-05**. 학습 구간 체결/자본 이익은 결과에 포함되지 않음.
- 기존 10건 이상의 완료 왕복 거래 기준에 못 미쳐 세 전략 모두 **NOT_VALIDATED**. 특히 GPT G10은 양호한 샤프지수/수익률에도 완료 거래가 1건뿐이라 견고한 성과 추론 불가.
- 동일 세 계획에 **260/300/400봉 워밍업 민감도 검사**를 수행한 결과 세 수익률·MDD·샤프·완료 거래가 각각 동일했다. 적어도 이 세 계획/자료에서 해당 길이 선택은 결과를 바꾸지 않았다.
- raw buy-and-hold 시세 변화는 기존 계산 +20.66%였으나 분배금·각 전략 비용과 조건이 같지 않아 비교 참고치일 뿐.
- 187봉 2026년 구간은 개발 당시의 QQQ 2020~2025년 이후 자료라 시간상 분리돼 있지만 Tiingo 최신 수정 기반이다. 과거 시점별 입력 데이터의 완전성을 독립 인증하지 못했으며 **공식 as-of/PIT 또는 봉인된 OOS가 아님**. 현재 보고서 작성 시점에는 이 데이터 결과를 이미 본 상태이므로 앞으로 이 구간을 다시 완전한 비관찰 holdout으로 이용해서는 안 된다.
