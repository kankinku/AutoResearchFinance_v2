## 결과 한계와 발견된 결함 가능성

1. **이 비교만으로 GPT 연구의 우월성은 입증되지 않는다.** 서로 같은 QQQ 기간의 반복 탐색이고 GPT는 직전 3세대 실험에서 유사 알고리즘의 결과를 본 상태였다. 무작위 정책은 1개 시드로 사전 고정됐고 적응하지 않는다. 시장 편향/사후 선택/상호상관/표본 수 부족을 통제하지 않았으며 신뢰구간, 유의한 알파, 인과나 실거래 수익 확률을 추론할 수 없다.
2. 통제 실험의 `REMOVE_REGIME_FILTER`는 양 분기를 모두 포함하는 Plan의 바깥 `plan_regime` 필터를 제거해도 실제 진입/청산 조건을 바꾸지 않을 수 있다. 이번 실행에서 해당 비교는 모두 `NO_OBSERVED_EFFECT`로 기록되었다. S7 실패가 아니라 **실험 설계 정보가 낮음**을 뜻한다. 다음 개발에서는 불필요한 대조 실험 사전 감지와 투표 임계값, 분기 자체 제거/교체 등의 실행 귀속 실험을 우선 검토할 것.
3. S7의 `CHANGE_POSITION_SIZE=70`에 의한 MDD 감소는 기계적 자본 배분 효과이며 기존 전략의 신호 품질 향상이나 원인 추론으로 승격 금지.
4. 최초 기준 통과율 차이는 본 자료에서의 탐색 기술에 대한 관찰이다. 다시 사용한 데이터로 선택된 전략을 독립 검증했다고 표기하지 않는다.
5. 새 도구가 이 ChatGPT 연결에 여전히 노출되지 않아 인증 앱 10세대는 수행하지 못했다. **기존 앱의 도구 목록 새로고침/새 채팅 이용**, 동일 MCP URL/OAuth 유지, 앱 재등록·키 회전·별도 LLM API 자동 전환 금지.

## 이후 작업 순서

P0. 기존 Quant 앱 연결에서 MCP 스키마 갱신 후, 신규 연구 도구 직접 호출 2~3세대 → 10세대 입출력 원장 테스트(수익 성과 판단과 분리).

P1. 독립 holdout 데이터와 역사적 as-of/기업행동 시점 보증 확보, 데이터/시장/기간 여러 조합으로 반복. 단일 QQQ 10세대 결과 재사용을 수익성 검증으로 재분류하지 말 것.

P1. 통제 실험 정보량 확대: 자동 무효 ablation 감지, 실제 체결 시점 변화가 있는 대안 규칙, 동등 budget·복수 seed를 가진 무작위 탐색과 비교, 통계적 불확실성.

P2. 관련 지표 S6 검증 범위/시장별 적용 확장, S8 자율 예산 조절·탐색/진화 권고의 가치를 별도 공정 실험으로 측정. 실거래 주문 계속 비활성.

**확정 결론**: 모델 작성→MCP SDK 계획 제출→실제 개발 자료 평가→모델 진단 제출→S7 자동 저장→S8 권고의 10세대 수직 체인은 확인. 인증된 앱 도구 경로, 외부 PIT/OOS, 지속형 무인 연구 및 미래 순수익 우위는 아직 확인되지 않음.
