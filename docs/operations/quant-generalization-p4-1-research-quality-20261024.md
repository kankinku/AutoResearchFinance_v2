## 목적과 실제 수정
기존 P3 부모 선정은 전체 개발 수익, MDD, 최악 연도 상대 성과를 사용했지만 시장에 단지 2.19%만 노출된 후보의 MDD가 낮다고 해서 투자 방어 능력이 입증되는 것은 아니었다. P4-1은 **새 격리 연구 세션이 명시적으로 P4 quality policy에 가입할 때만** 다음 장치를 작동한다.

1. **사전 선언 적격성:** 원본 체결·결정 감사 후 전체 시장 노출률 20% 미만 또는 완료 거래 10건 미만의 전략을 신규 부모 후보에서 제외하고 `LOW_EXPOSURE_LT_20_PERCENT`, `LOW_TRADES_LT_10` 이유를 기록한다. 이는 연구용 선별 기준이며 통계적 유의성·실계좌 수익성 기준이 아니다. 모두 탈락하면 적격 부모 부족 오류로 중단한다. **유효한 방어 전략이라도 이 기준으로 제외될 수 있으므로 이후 별도 방어자산/시장중립 평가 경로가 필요하다.**
2. **비교 기준 보정:** 동일 QQQ 2020~2025 비-PIT 일봉/기존 next-open 거래비용 엔진으로 (A) QQQ 100% B&H, (B) 후보가 실현한 전체 노출률만 최초에 QQQ로 배정하고 나머지는 현금으로 남긴 비교군, (C) 전략 실현 일간 변동성에 사후 보정한 QQQ/현금 비교군을 산출한다. B/C는 **EX-POST 설명용 프록시**일 뿐 동일한 동적 익스포저, 실제 사전 선택, OOS 초과성과의 검증이 아니다. C는 QQQ 100%를 초과하는 위험을 레버리지로 맞추지 않으며 capped 플래그를 남긴다.
3. **선정 순서:** 성장 경로는 노출 보정 QQQ 프록시 대비 누적 초과수익을 우선하고, 방어 경로는 같은 노출 QQQ 프록시 대비 MDD 개선폭을 우선한다. 일관성 경로는 최악 연도 QQQ 초과성과 중심으로 평가한다. 이미 증명된 기존 연도별 Pareto 후보군은 유지하며, 독립 OOS 성적이라고 승격하지 않는다.
4. **감사·무결성:** 각 후보의 full-audit 비용/곡선, dataset hash, risk/exposure 프록시 요약 해시, 탈락 사유, 선택 결과를 품질 리뷰·새 parent selection receipt에 보존한다. schema/이상치/다른 데이터 해시/조작된 프록시/OOS 표기/잘못된 노출·거래수는 fail closed.
5. **레거시 보존:** 기존 `AUDITED_EX_POST_PARENT_V1` 등록은 품질 정책으로 전환하지 않는다. 신규 세션에 `AUDITED_EX_POST_PARENT_P4_QUALITY_V1`로 등록하며, 생성·재연결 모두 명시적 환경 플래그가 필요하다. 기존 pinned selection은 최초 해시 검증 후 변경 없이 반환. OAuth/MCP 고정 URL/운영 대시보드/실거래 승인/OOS 상태는 수정하지 않았다.
