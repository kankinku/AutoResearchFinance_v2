# T-007 partial — deterministic per-fold candidate generation

The development-only walk-forward selection previously generated a candidate cohort once for the entire evaluation and then ranked that cohort separately in each fold. It now regenerates candidate mutations/parameter proposals separately **after constructing the training slice for each fold**; data-blind IR generation is seeded by `base_seed + fold_id`. Each fold ranks only those fold-generated candidates on its own earlier training bars, freezes the winner and evaluates the winner on the following chronological test window with warmup-only history and no pre-test orders.

Each fold's immutable Evidence and local response record `generation_seed`, `generated_candidate_hashes`, candidate count and `candidate_generation_cutoff_at`, alongside training data hash, training/test timestamps and train/test metrics. Duplicate candidates are semantically removed per fold and `selection_trials` counts the actual number of fold evaluations rather than assuming all folds have an identical number of candidates. The separate whole-cohort exploratory funnel is unchanged, and must not be misrepresented as independent OOS.

**Material limitation:** The parameter mutation generator is intrinsically data-blind, and the upstream parent strategy/AI hypotheses may already reflect future history. Therefore `upstream_selection_verified=false` and `sealed_oos_evaluated=false` remain. Previously observed Bayesian fitness data without as-of lineage still fails closed. This is reproducible fold-local proposal generation, **not an end-to-end independently audited model-selection protocol**. Real PIT feature release timestamps, fold-local researcher training, sealed OOS, and authorized promotion remain pending.

Tests: `tests/orchestration/test_train_only_selection.py` asserts one global diagnostics generation plus independent fold generation, deterministic per-fold seeds and identities, and unchanged first-fold selection after future price perturbation. The evaluation runner test asserts the same data is serialized in both response and immutable Evidence.
