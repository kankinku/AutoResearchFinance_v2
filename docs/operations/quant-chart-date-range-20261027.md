- 배포 대상: 원본 Quant 대시보드 /academic/ 및 /quant-research/, 기존 인증·MCP·연구 원장 불변
- 변경된 UI: 시작일/종료일 `type=date` 선택, '선택 기간 확대' 적용, 기존 '전체 기간' 버튼으로 복원
- 차트 동작: 검증된 일봉/체결/자산곡선을 **재가공하거나 잘라내지 않고**, Lightweight Charts의 timeScale visible range만 캔들/자산곡선에 공통 적용
- 캔들 데이터 경계 내 2020-01-02~2025-12-31만 선택 가능 (현재 검증된 QQQ 세션 기준). 거래일 없는 기간·시작/종료 반대·범위 밖 입력은 실패 상태 안내 및 이전 유효 확대 유지
- 하루 선택 시에도 시간축 너비를 확보해 표시하며 매매·신호 마커 유지
- 실행/세대 전환 시 기간 선택·이전 VERIFIED 상태 초기화. 날짜 입력 전에는 확대 버튼 비활성화
- 중요: 수익률·MDD·손익 KPI는 **전체 백테스트 기간 기준**으로 남고, 확대 기간의 성과라고 표시하지 않음
