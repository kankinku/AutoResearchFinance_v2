# T-011 — run-scoped Frontier parent resolution in the active research loop

The Research Director exposes a `parent_ids` field, but previously the live proposal preflight, repair preflight and evaluator always used the currently active `StrategyIR`; any alternative requested parent was silently ignored. A promising Frontier strategy could be recovered from immutable Evidence but could not actually be passed to the local evaluation worker as a new base IR.

`select_intent_parent` resolves exactly one requested parent: either the currently active strategy, or a hash-checked, Pydantic-valid, eligible Frontier parent stored in an attempt **within the same research run**. `build_generation_context` now announces `replayable_parent_ids` separately from historical metadata-only Frontier records. `run_autoresearch` invokes resolution before proposal and both types of repair preflight, passes the resolved IR as `strategy_override` for normal/repaired evaluation, and records that parent's ID in the generation summary. An unsupported multi-parent operation or unrecognized/cross-run parent is an error handled by the bounded repair/fallback policy; if fallback is required, selection explicitly resets to the active strategy rather than accidentally evaluating a prior invalid parent.

Existing historical Frontier summary remains read-only. Existing Legacy records with no Strategy IR never become executable parents. Injected evaluators cannot gain a parent merely by returning an unverified `best_strategy`; a valid immutable attempt is required for *Frontier* parent reuse.

Test coverage: `tests/runtime/test_research_generation.py` checks same-run/cross-run scope and unsupported multi-parent claims; `tests/runtime/test_autoresearch_loop.py` exercises a two-generation loop that evaluates the newly selected parent after a prior eligible attempt. This is still only single-parent source execution; true crossover with multiple strategies, an intentionally designed Rescue Pool, independently sealed OOS and authorized champion promotion remain unimplemented.
