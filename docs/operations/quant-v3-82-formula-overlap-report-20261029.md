# Quant V3 · 명칭 비교를 통과한 82개 출력의 수식 중복 정밀 감사

**2026-10-29 KST / 연구 브랜치 research/v3-strategy-evolution / 운영 등록 변경 없음**

## 결론

기존 연구 지표 **435개**와 동일 이름이 아니어서 남았던 **82개**(Pandas TA Classic 신규 수치 후보 145개 중 이름 중복 계열 63개 제외)를 **실제 Python 수식 코드, 원본 출력별 변수, 기존 native FeatureSpec 및 Calculator**와 교차 비교하였다. 이전의 **'이름 안 겹침' 82개를 독립 지표 82종이라고 보고하면 안 된다.**

| 수식 판정 | 출력 | 독립 신규 수식 집계 |
|---|---:|---|
| **기존과 수식 일치 또는 상수·배율 변환으로 대체 가능** | **16** | **0** (중복 확정 후보) |
| 동일 지표 계열이나 계산 방식·기간·초기화 등이 다른 구현 | **26** | 확정 불가 (별도 parity review 필요) |
| 기존 지표 계열에서 아직 따로 노출되지 않은 보조선·밴드·상태/입력별 출력 | **34** | 신규 *출력 채널* 후보, 독립 알고리즘 수에 추가하면 안 됨 |
| **435개 FeatureSpec에서 직접 대응 수식을 못 찾음** | **6** | 신규 *수식 출력 후보* 6개, 독립된 기능 계열로 보면 **4계열** |
| **합계** | **82** | 중복 16개 식별, 나머지 66개는 별개 실행 가치 평가 필요 |

**엄격한 해석:** 명시적인 중복 16개는 이식하지 않는 것이 타당. 기존 family 26개는 '동일 목적'이더라도 실제 계산이 다를 수 있으므로 **중복으로 확정·삭제하지 않음**. 34개는 같은 지표의 추가 출력(도움이 될 수 있음)이며 원본 소스 접근성·PIT·원장 보호가 충족된다면 이식할 수 있다. 신규 수식 6개 역시 확정된 성공 전략이나 원본 숫자 parity 검증 완료를 뜻하지 않는다.

## 16개 기존과 대체 가능한 출력을 구체적으로 확인

소스 함수 / 수학 대응 / 기존 435 지표:

- `mom[0]` = N기간 가격차 = `momentum`.
- `rocp[0]` = N기간 수익률 = `returns`.
- `rocr[0]` = 1 + N기간 수익률, `rocr100[0]` = 100 × (1 + 수익률). **ROC 계열에 새로운 정보가 없음**.
- `log_return[0]` = N기간 로그수익률 = `log_returns`.
- `linreg[0]` = N기간 최소제곱선형회귀 종점 = `linear_regression`.
- `willr[0]` = 윌리엄스 %R = `williams_r`.
- `bias[0]` = 종가/SMA − 1 = `bias_ratio`.
- `brar[0]`/ `brar[1]` = AR/BR 공식 = `brar_ar`/`brar_br`.
- `cti[0]` = 시계열 상관관계 추세지수 = `correlation_trend_indicator`.
- `er[0]` = 카우프만 효율비율 = `efficiency_ratio`.
- `kdj[2]` = KDJ의 J선 = `kdj_j`. **K/D 보조선([0],[1])은 별도 출력으로 보류**.
- `stdev[0]` = 같은 N기간 표준편차 = `standard_deviation`; 모집단/표본 오해를 피하기 위해 동기간 두 구현의 실제 동일 output을 확인.
- `chop[0]` = 같은 CHOP 지수 = `choppiness_index`.
- `vhf[0]` = 같은 VHF 지수 = `vertical_horizontal_filter`.

이 16개는 pinned MIT 원본 수식과 현재 native Calculator 식을 검토하고 기본기간을 **동일하게 20바**로 조정하여 **480개 합성 OHLCV 구간**에서 일치 검증. 추가로 가격 추세를 반전시키고 거래량을 변화시킨 **480개 대체 합성 OHLCV 구간**에서도 수치·결측 mask가 일치하는 회귀 테스트 확인. 잔차는 일반적인 부동소수점 허용 오차 수준이다. **검사한 파라미터·합성 데이터 범위**의 일치이며 모든 결측·모든 사용자가 조정한 파라미터의 완전 동치 정리를 증명하지 않는다.

주의: 이전의 'AD 매집분산선' 잠정 일치도 **원본에서 open 입력을 제공하면 (close−open) 기반으로 달라지는 설정**이 있다는 점을 발견해 **16개 확정 중복에서 제외**하고 *계산 방식 차이*로 분류했다. 실제 82개 후보의 호출 계약을 적용한 판정이다.

## 26개: 같은 계열이지만 현재 구현과 달라 무조건 중복 삭제 금지

핵심은 동일 지표 이름을 **현재 단순화된 계산기와 원본 수식이 공유한다는 사실만으로** 동일하다고 판단할 수 없다는 것이다.

- `ht_dcperiod`·`ht_dcphase`·`ht_trendline`은 pinned Hilbert 계산 경로가 있고 현재 `dominant_cycle`·`hilbert_phase`·`hilbert_trendline`은 다른 계산/근사 경로를 사용함.
- `lrsi`는 라게르 필터를 적용하지만 기존 `laguerre_rsi`는 다른 RSI 근사일 수 있음.
- `massi`, `hvol`, `mcgd`, `natr`, `vosc`, `sarext`는 기간, 시드, 표본정의 또는 사용 입력에 따라 수치가 달라질 수 있다.
- 도지, 잉걸핑, 하라미, 하이웨이브, 인사이드바 등 캔들 패턴은 원본의 길이별 몸통·그림자 조건과 기존 간이 판별기 조건이 달라 **동일한 패턴 family 안에 다른 구현**일 수 있다.

같은 family 26개는 **별도 원본 수치 oracle·국면별 시그널 비교 후 채택·기존 교체·제외** 여부를 결정해야 한다.

## 34개: 새로운 계산 알고리즘 34종이 아니라 기존 family의 별도 출력

예: 하이킨아시 시가/고가/저가, 캔들 OHLC별 Z점수, KDJ K/D선, 스토캐스틱 D선, 파라볼릭 SAR의 상승·하락선/가속도/반전 상태, 샹들리에 숏 스톱, 가속 밴드 하단, 켈트너 밴드, ADX 평활, 써모미터 보조 신호, 이동평균 레인보우 5개 기간별 EMA 등.

이들 값은 기존 대표 지표 출력과 다를 수 있고 전략 특징으로 활용 가능하지만, **공통 기초 수식의 다중 출력**이므로 별개 수학적 발명으로 계산하면 안 된다.

## 6개: 현재 카탈로그에서 직접 대응 계산식이 없는 후보

| 출력 | 명시된 수식 | 구분 |
|---|---|---|
| `midpoint[0]` | (rolling max(close) + rolling min(close))/2 | 1개 새 가격 변환 |
| `wcp[0]` | (high+low+2×close)/4 | 1개 새 가중 종가 변환 |
| `drawdown[0]` | 누적 최고 종가 − 현재 종가 | 드로다운 계열 |
| `drawdown[1]` | 1 − 현재 종가/누적 최고 종가 | 위와 같은 계열, % 표현 |
| `drawdown[2]` | log(누적 최고 종가/현재 종가) | 위와 같은 계열, 로그 표현 |
| `adosc[0]` | EMA_fast(ADL) − EMA_slow(ADL) | 차이킨 매집·분산 **오실레이터**; 현재 `chaikin_volatility`와 별개 |

**6개 출력/4개 수식 계열**이지만, 기존 지표들을 조합해 재생산 가능한 단순 변환도 포함되어 있다. 따라서 자동 생성 후보 우선순위 판단에는 *새로운 수학 분야*가 아니라 *현재 등록 435개의 바로 쓸 수 있는 scalar 출력으로 제공되지 않는 수식*이라는 제한을 붙인다.
