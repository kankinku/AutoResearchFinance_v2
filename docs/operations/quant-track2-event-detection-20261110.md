# Quant [15/16] Track2 독립 이벤트 탐지 프로토타입 검증 보고

**검증일:** 2026-11-10 KST
**분리 브랜치:** research/v3-event-detection (main 기준)
**상태:** ISOLATED_PROTOTYPE_VERIFIED / REAL_EVENT_PERFORMANCE_BLOCKED / NOT_MERGED

## 무엇을 만들었는가

- 폭락·반등·변동성 급등의 **사후 사건 레이블** 정의와 **사전 경고 점수** 계산을 코드와 테스트로 분리. 임계값·기간·경고 예산·리드타임·희귀 사건 최소 개수는 구성 인자로 받으며, 사용자가 확정한 시장 기준으로 취급하지 않는다.
- 점수는 기존 승인된 FeatureRegistry의 QQQ 20봉 수익률을 계산해 만든 단순 기준선. 신규 지표의 미래 계산을 허용하거나, 이 점수가 고성능 경고기라고 가정하지 않는다.
- 고정 점수 임계값에 의해 시간 순서대로 경고를 발행하고 연도별 경고 예산·쿨다운을 적용. 사후에 연도 전체에서 점수가 높은 경고를 골라서 사전 경고인 척하는 경로 금지.
- 마지막 리드타임 구간은 right-censor. PR-AUC의 동점 집계, 1사건-1경고 매칭, 사건 recall·경고 precision·실제 리드타임, 252개 적격 봉당 거짓 경고(연당 근사치), 무경고·동일 예산 항상경고 기준선을 계측.
- 각 **경고 원장**에는 그 경고의 날짜까지 관측한 가격 접두 SHA만. 이후 가격이나 레이블은 사후 리포트에만 둔다. 봉인 OOS 구역·계좌/주문/Track1 연구 연동 코드 없음.
- 기존 계획이 참조한 2026-10-27 Track2 명세 파일은 현재 저장소에서 찾지 못함. 과거 문서 원문을 재구성했다고 주장하지 않고, [새 실험 명세](../plans/v3-track2-event-detection-20261110.md)와 [분리 범위 ADR](../decisions/2026-11-10-track2-isolated-research-approval.md)을 함께 작성함.

## 오해 방지: 완전 합성된 진단 예시

실제 QQQ가 아닌 **260개 합성 종가**를 만들어 네 번의 임의 급락을 삽입한
고정 예시. 실험 변수 예시(절대 사용자 승인 임계값 아님):
2봉 10% 급락 레이블, 1~4봉 리드타임, 연 2회 경고, 임계 점수 4%,
최소 사건 2개. 이는 **작동 테스트**일 뿐 시장 예측 성과를 의미하지 않는다.

- 평가 기회: **236회**, 사후 사건 **4회**, 기회별 양성 비율 **6.78%**.
- 단순 점수의 평균 정밀도 **6.78%** = 동일 점수 기준선의 양성 기저빈도
  **6.78%**, **예측력 향상의 근거 없음**.
- 예산 적용 경고 **2회 / 실제 사건과 매칭 0회 / 거짓 경고 2회**.
- 항상경고 동일 예산 기준선 역시 2회 경고/0회 적중; 무경고는 0회.
- 단일 합성 경로로 재현되므로 모든 수치의 성과·신뢰구간·미래 경고
  비용·경제 효과의 의미 있는 추정은 **불가능**.
- 산출물 필수: 출처 진본 확인 불가, 실제 OOS 비허가, 주문 비활성,
  인과성 미확립, 독립 수익성 주장 금지.

## 남은 차단과 운영 방침

1. 원본 시세와 시점별 publication/revision/기업행동, 충분한 실제 사건
   개수·기간, 지표 계산 시각·봉 마감, 사전 고정 프로토콜/SHA·경고 예산을
   확보하기 전 시장 성능 비교를 실행/합격 처리하지 않는다.
2. 이벤트 탐지의 실제 PR-AUC/오경보 및 리드타임이 독립 기간에서
   무경고·항상경고 대비 재현되어야 하며, 임계값·종목·라벨 규칙 사후
   변경은 별도 시험으로 새로 기록한다.
3. **절대 병합·연결 금지:** 현재 연구 프로토타입을 Track1 자율 전략의
   추천/학습 기억에 자동 입력하거나 Track3 봉인 OOS/모의주문/실거래와
   연결하지 않는다. 별도 승인·독립 리뷰 전 release NO-GO.
4. 본체 16단계 중 [14/16] V07의 엔진/실모델/독립 경제성 **NO-GO**
   판정은 변하지 않는다. 이 단계로 실제 GPT T4 검증을 대체하지 않는다.
