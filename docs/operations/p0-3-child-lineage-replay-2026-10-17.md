# Quant Autoresearch P0-3A — 자식 StrategyIR 재현과 계승 실험 원장

기준: 2026-10-17. 운영 MCP URL, OAuth, 32개 도구 이름, 133세대 원본 기록, 거래·데이터 게이트를 그대로 유지한다.

## 구현된 기능

- `research/llm/lineage_replay.py`: 기록된 세대 AlgorithmPlan으로 원본 부모를 재컴파일·감사하고 원본 플랜/전략/데이터/감사 해시 및 종말 자본을 확인한다. 저장된 S7 실험의 보고서 SHA, 가설 ID, 기존 자식 StrategyIR 해시, 체결 수, 실제 비용, 최종 자본을 다시 확인한다.
- 성공한 자식(원본보다 개발 수익 높음, 완료 매매 30건 이상)만 후속 변형을 허용한다. 표준 StrategyIR 타입의 등록된 연구 피처로 1~6개의 구조 변경을 자식에 추가하고, **바뀐 실제 체결**, 해시, 비용, 거래 수, 수익률, 낙폭을 측정한다.
- `evaluate_algorithm_experiments` 기존 도구에 선택적 `checkpoint_token/hypothesis_id/child_strategy_hash/continuation_intent`을 함께 제공하면 이 자식 후속 실험을 수행한다. 기존 `session_id/generation`만 전달하는 API는 종전 S7 보고서 읽기/평가 기능을 그대로 유지한다.
- 결과는 신규 SQLite 테이블 `successor_lineages`에 기존 generation evidence와 **분리하여** 소스 증거 해시 및 후속 전략 해시로 보존한다. 같은 요청 재호출은 저장된 결과만 반환한다. 원본 실험·세대 카운터·체크포인트 토큰은 변하지 않는다.
- 모델 컨텍스트 `verified_successor_lineages`에 원본 자식·후속 전략 해시, 후속 변경 명세, 측정 성과를 제공해 다음 GPT 연구 가설에서 참고한다.
- 데이터 스코프는 `DEVELOPMENT_NON_PIT`이며 자동 자본 투입·실거래 주문·OOS 인증·정식 세대 승격은 **불가**.

## 확인한 실제 계승 예시

새 101–200세대 세션 내 로컬 **29세대** (전역 129세대)의 S7 대조 자식:
- 재현된 자식 누적 수익률 **+44.44%**.
- 그 **실제 자식 StrategyIR**에 `time_series_momentum > 0.5` 추가 → 후속 연구 수익률 **+48.95%**.
- 다른 자식에 동일 조건을 추가하면 수익이 오히려 악화되는 사례(로컬 5, 32세대)도 확인. 결과는 모두 동일 개발용 2020~2025 QQQ에서 얻은 것으로 과적합 가능성이 크다.
- 실제 개선이면 자동 승격되는 것이 아니라, 후속 실험의 재생 가능한 부모 후보로만 등록한다.

## 완료로 간주하지 않는 항목

**P0-3B:** 다음 *정식 counted generation*의 부모를 이전 자식 StrategyIR로 선택하고, 그로부터 S2 진단/S7 대조/중복 신호 방지/예상 중단 복구까지 통합하는 작업은 남아 있다. 현행 `AlgorithmPlan` 컴파일러는 임의의 S7 자식 진입·청산 규칙을 그대로 직렬화하지 못한다. 해당 부분을 우회해 새 세대가 부모를 계승했다고 표시하면 부정확하므로 금지한다.

다음으로 P0-3B를 진행해야 하며, 그전까지 별도 계승 원장은 세대를 증가시키지 않는 수동 GPT 연구다.
