기준 2026-10-28 KST. 단계 T1-02/S6/S9 · 사용자 승인 Q05/Q10/Q11/Q12/Q18. **이 문서의 330은 오픈소스 파일명의 정규화 후보 330개이지, 독립적인 전략 인디케이터 330개가 아니다.** 4개 소스의 함수·수학적 동의어·캔들 이름·출력 변형·다중자산 데이터 요구 사항을 포함한다.

## 정량 결과

- 전수 분류: 원래 미이식 후보 **330/330 항목**, 개별 항목별 출처·이름·처리 상태·이유를 `quant-v3-330-source-full-disposition-20261028.json`에 보존.
- 3차 신규 실행 가능 기능: **107개 scalar 출력**, 소스 후보 그룹 **103개**.
  - MIT `pandas-ta-classic`에서 인과적 prefix·유한값·바정렬 검증을 통과한 신규 **95개**. 원본 소스 코드의 MIT 라이선스/알고리즘 동작을 보존해 빌드 가능한 연구용 자체 패키지로 복제했다.
  - BSD TA-Lib C 수식 **5개**, Apache Stock Indicators C# 수식 **7개**를 OHLCV 인과적 Python 수학식으로 구현. 다중 출력 그룹이 있어 **원본 후보 그룹은 8개**.
- 이전 1·2차 신규 41개에 이번 107개를 더하면, 기존 기초 173개에서 **총 연구 지표 321개**(173+41+107).
- **전수 분류의 상태**(330명 기준):
  - 신규 함수 구현 103개 소스 후보 그룹/107개 scalar 출력
  - 중복 이름·패턴 계열/수학 유틸리티/동의어 등 보수적 분류 **152개**
  - 코드 이식·라이선스·타 시스템 API 호환성 미검증 **68개**
  - 테스트 실패/미래 참조 의심 **6개 격리**
  - 외부 시점 데이터 부족 **1개 차단**
- **동일 이름/계열이라고 수학적 동치성이 최종 증명된 것은 아니다.** 특히 37개 `EXCLUDED_KNOWN_INDICATOR_FAMILY`는 계열 중복으로 새 지표 등록을 유예한 것뿐이며, 별개 수학식을 가진 출력 가능성을 추가 검토해야 한다. 330개 전부 실제 활성화되었다고 표현해서는 안 된다.

## 출처 및 배포 범위

1. `pandas-ta-classic` MIT, SHA `7c669b033582d53b70aa68b6388796d19ce33979`. `pandas_ta_classic/`에 upstream Python 원본 312+ 파일 복제, 라이선스 원문과 `PINNED_SOURCE` 보존. Upstream setuptools-scm 생성 파일 `_version.py`만 고정 커밋을 표시하는 빌드용 메타데이터로 생성. 코드 안에서 직접 주문/계좌/인터넷 접근하지 않는다.
2. TA-Lib BSD-3, SHA `4334163d3a1f5019aa9051342316b936a4dfb994`. 5개 독립 계산 함수만 재구현. C 확장이나 빌드 아티팩트는 이식하지 않음.
3. Stock Indicators Apache-2.0, SHA `da428182d0e222339b662bc8ac645596102260bd`. 7개 독립 계산 출력. Alligator은 원본 표시용 미래 x-bar plot shift를 **제거한 현재바 인과적 평활값**으로 정의; 원본 그래프와 시차가 동일하다고 주장하지 않음.
4. Tulip Indicators LGPL-3, SHA `be18abb13e075ba866898dcc7cb52399603302a6`. 복제·조사만 하고 라이선스 준수 없는 직접 이식/바이너리 결합 금지.

## 코드 경로

- `core/features/pandas_ta_manifest.json`: 95개 기능, source 함수명, 입력 계약, 출력 인덱스, pin SHA.
- `core/features/pandas_ta_pinned.py`: manifest whitelist 전용 함수 호출, 이전 바만 참조, 결과 유한값·바 길이 검증 및 `None` 처리. 입력 매개변수로 함수명/타 소스를 바꾸려는 요청을 거절.
- `core/features/source_multi_backend.py`: TA-Lib·Stock 수학식 12개, 미래조회 없이 원본 C/C# 알고리즘의 정의를 검토하고 완성된 바 t까지 계산. 서드파티 런타임과 KIS 의존 없음.
- `core/features/catalog.py`, `core/features/calculators.py`: 기존 214개에만 신규 스펙 추가, 충돌 없이 `research_feature_specs()`와 inherited `FeatureRef` 경로에서 사용 가능.
- 전체 330개 자동 분류 재현: `scripts/v3_audit_330_source_names.py`. 4개 원본 SHA/라이선스 증거, 각 항목의 파일 이름과 상태·사유를 JSON에 기록. 임의 `REGISTERED`로 대량 승격하지 않음.
- `pyproject.toml`: MIT 패키지 빌드 포함, 원본 라이선스/핀 포함. Python 3.11+, NumPy 2+가 필요한 업스트림 의존 부분은 배포 환경 적합성 별도 확인 필요. 현 V3 Track1 개발 검증은 Python 3.12 / NumPy 2 환경에서 실행되었고, 프로젝트가 명시하는 Python 3.10 하한과의 통합은 **미검증**.
