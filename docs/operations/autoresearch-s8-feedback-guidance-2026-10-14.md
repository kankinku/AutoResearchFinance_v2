# S8 1차 — 증거 기반 자율 탐색·진화 방향 권고

기준일: 2026-10-14. 목적은 개발자가 QQQ 전략을 계속 손으로 튜닝하는 대신, 각 세대의 기록과 검증된 통제 실험을 **외부 GPT 연구 책임자에게 전달**해 연구 방향 선택을 돕는 것이다. 이는 자율 실행의 실행기와 실증된 개선 알고리즘 자체가 아니며 S8 전체 완료 기준(동일 계산 예산에서 무작위 대비 우수성 비교)을 충족하지 않는다.

## 기능

- `research/llm/adaptive_direction.py`의 순수 함수 `build_research_direction(history, controlled_reports)`로 **최대 100개 완료 세대**의 해시로 식별된 역사와 각 세대에 저장된 S7 v2 통제 실험 결과를 분석한다.
- `application/academic_checkpoint_service.py`의 다음 알고리즘 설계 `model_context.research_direction`에 결과를 삽입한다. 기존 통제 실험 저장소의 체크섬을 재검증하고, 해당 세대의 원장 `evidence_hash`와 실험 기록의 원본 해시가 일치하는지 확인한다.
- 다음 방식 중 하나를 **권고**한다: `EXPLORE`(새로운 구조 탐색), `TEST_HYPOTHESIS`(직전 손실·관측 가설을 통제 실험), `EVOLVE`(수정으로 신호/체결 타이밍에 관측된 유의미한 구조 변화가 있었던 경우 개선 연구). 학습 대상 지표로 완료 세대 수, 중복된 전략 정체성, 관측된 대조 실험 수, 효과 없음/예상 방향과 다름/예상 방향 일치, 신규·제거 체결과 수량 변경 여부, 복수 비교 수행 여부를 사용한다.
- 아무런 완료 세대가 없으면 `EXPLORE`, 직전 완료 세대에 검증하지 않은 가설이 있으면 `TEST_HYPOTHESIS`, 동일한 지표 수정이 **체결을 바꾸지 않았으면** `EXPLORE`를 제안한다. 수익·MDD의 방향이 맞더라도 **투자 비중만 감소**한 경우 전략의 우위로 간주하지 않고 추가 검증을 제안한다. 실제 체결 시점 변화가 수반된 단일 대조 실험에서 예상 방향과 일치하면 제한적으로 `EVOLVE`를 권고한다.
- `llm_may_override=true`, `allocation_is_not_fixed_quota=true`로 **정해진 50:30:20 탐색 비율이나 고정 세대 할당량이 아니다**. 본 기능은 다음 가설을 생성하거나 백테스트를 자동 호출하지 않으며 사용자 지시 없이 주문하지 않는다.
- 모든 출력은 `RESEARCH_BUDGET_GUIDANCE_ONLY`, `causal_status=NOT_ESTABLISHED`, `independent_oos_approved=false`, `real_trading_enabled=false`를 명시한다. **개발 구간 누적 수익률을 정책 보상의 근거로 사용하지 않는다**. 어떠한 모드 추천도 실전수익 확률이라고 주장하지 않는다.
- 이전 S7-v1 저장 보고서는 체결 귀속 필드가 없으므로 다음 모델에게 기존 `prior_research` 사실 그대로 보이지만, S8의 정량화된 검증 성과 횟수에는 넣지 않는다. 옛 보고서 자체를 수정·재해시하지 않으며 S3/S6 카탈로그 변경도 없다.

## 검증

- 무이력, 최신 가설 미검증, 효과 없는 변경, 예상과 반대, 규모만 줄인 거래, 신호 타이밍이 바뀐 대조 실험, 복수 비교, 중복 전략 정체성, 변조된 해시/거래 수를 테스트한다. 기존 S8 사용자 의도인 **선택 기준의 유연성**과 **반복·무의미한 실험 억제**에 집중한다.
- MCP 통합: `AlgorithmPlan` 첫 컨텍스트에는 `EXPLORE`를 제공; 1세대 LLM 진단 완료 후 미검증 상태는 `TEST_HYPOTHESIS`; S7 실제 실험이 저장되면 같은 컨텍스트에 방향 판단 근거를 추가. 세대 history와 원본 Evidence는 변하지 않는다. S7-v1 legacy 보고서 조회도 유지한다.
- 이미 저장된 QQQ 2세대 연구를 SQLite 읽기 전용 복제본에서 재조립해 유효성 확인: `s3-v1` 원장 2세대의 해시 불변, 신규 권고 상태는 직전 미검증 가설을 바탕으로 `TEST_HYPOTHESIS`, OOS/실거래/인과 인증은 모두 false.

## 남은 본질적 완료 기준

1. **S4/S5:** ChatGPT 클라이언트에서 실제로 매 세대 연구 의사결정을 수행하고 10세대 이상 요청 후 회복까지 확인해야 한다. 현재 서버 내 독립 GPT 호출/무인 연구 루프는 없다.
2. **S8:** 같은 세대 수/평가 횟수/데이터/비용 예산의 **무작위 탐색 베이스라인**과 비교해 유효 신규 후보 증가, 중복률 감소, 원인 가설 평가 정확도, 리소스당 개선 정도를 사전등록한 실험으로 비교해야 한다. 현재는 휴리스틱 권고에 불과하며 **수익·연구 효율 우위 미검증**.
3. **S10:** 실제 순현금수익/시장 독립성 검증은 별도 OOS·PIT·거래비용·다중검정 단계에서 다루며 자동 주문 승격은 없다.

## 운영 안전 원칙

기존 `https://project-moon.taild689f9.ts.net/quant/mcp`와 승인키, OAuth SQLite, nginx 및 보호된 백테스트·브로커 경로를 절대 변경하지 않는다. 새 기능은 기존 도구의 `model_context`를 **부가적으로 확장**하며 MCP 도구수 **32개를 유지**한다. 새 버전 고정 Worktree를 배포하되 기존 운영 Worktree를 보존하고 GitHub 개발·배포 브랜치를 분리한다.
