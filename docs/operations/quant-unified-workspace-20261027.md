# Quant 통합 연구 대시보드 — UI/UX 통합

검증일: 2026-10-27 (KST)
대상: 기존 원본 Quant 운영 UI, 동일 인증 origin `/academic/` 및 `/quant-research/`.

## 무엇이 바뀌었는가

- 기존에는 개발 차트 `/`, 사후 2026 구간 `/oos`, 연구운영 `/research`이 각기 별도 페이지였다. 이제 **기본 화면 하나**에 동일 문서 탭으로 연결.
- 상단: `개발기간(2020~2025)`, `2026 검증(G124 · 사후 OOS)`, `연구 운영` 세 탭. 브라우저 URL의 `?view=oos` 및 `?view=operations` 직접 링크, 뒤로 가기, 키보드 좌우 탭 이동 지원.
- 개발차트는 기존 48개 감사 재현 전략, 검증된 체결/QQQ 캔들, 원본 하위 원장/전략 비교를 그대로 사용.
- 2026 패널은 기존 G124(2026-01-02~2026-10-26, 205봉, 20체결) 사후 OOS 증거만 **지연 로딩**. 재실행/LLM/주문 기능 없음, 기존 SHA·증거 검증 지속.
- 공통 성과 비교: 원본 개발기간 G124 +201.1%, 2026 사후 결과 -5.2%, 같은 기간 QQQ 단순보유 +14.8%; 동일 전략 해시/원본 감사 상태를 대조하지 못하면 연결 실패로 표시. **개발기간과 2026 성과를 합산하지 않음**.
- 편의성: 비교 카드에서 G124 즉시 선택 또는 2026 검증 전환, 선택 세대·기간 확대 보존, 각 차트의 1·3·6개월 빠른 확대/전체 기간, 날짜 직접 입력 가능.
- 연구 운영 탭에서는 기존 `/api/dashboard` 읽기 전용으로 현재 세대, 개발 선두 후보, 연구 서버 상태를 조회. 원장 상세는 기존 `/research` 연결. 원본 연구 운영 상태와 P9 차트 증거 시점(146세대 캡처)을 동일 정보로 착각하지 않도록 구분.
- 동일 페이지 내 JS/CSS/표준 상태 표시, 동일 색상·패널·메뉴 체계. iframe 사용 없음, 기존 인증/X-Frame-Options 불변.
- URL 호환성: `/oos`, `/chart`, `/research`, `/backtest` 종전 경로 모두 유지. 메인 탭은 기존 Quant 메인 주소에서 진행.

## UX 검증

- Chromium 데스크톱 1440×900 및 모바일 390×844에서 같은 페이지의 개발 → 2026 → 연구 운영 → 개발 전환 및 G124 선택/기간 확대 상태 보존.
- `/?view=oos` 직접 접속, 브라우저 뒤로 가기, 1개월/3개월/6개월 빠른 확대, 2026년 봉 검증 20개 체결, 원본 G124 +201.1%와 2026 -5.2%의 증거 체크 통과.
- 브라우저 JS 오류 0, HTTP 4xx/5xx 0, iframe 0, 모바일 가로 overflow 0.
- 비교 요약이 차트를 밀어내지 않도록 밀도 최적화: 데스크톱 화면의 가격 차트 블록 시작 약 432px, 모바일 약 552px. 이전 각각 약 556px·773px.
- 브라우저 로그 및 데스크톱/모바일 스크린샷: `state/unified-workspace-browser-20261027`.

## 보존·제약

- 개발기간은 원본 감사 재현한 48개 세대만 매매 차트 제공. 2026 사후 검증 완료 세대는 현재 **G124 1개**.
- 2026년 자료는 이미 관측한 Yahoo 최신 비PIT 가격 기반의 **사후 시간 분리 검증**, *봉인된 전향적 OOS가 아님*. 이번 UI 작업에서 추가 백테스트/후보 재선정/전략 학습 없음.
- 원본 Quant PythonMCP 고정 URL, OAuth, nginx Basic 인증/GET-only, 실거래 설정 및 연구 원장은 변경하지 않는다.
- 원본 기존 외부 `/academic/` 경로는 로그인 필요, 인증 실제 유저 자격증명으로의 최종 브라우저 확인은 수행하지 않는다.
- 차트 증거 백엔드 8096은 기존 Lab 독립 프로세스를 읽기 전용으로 사용한다. 중단 시 각 소스의 제공 실패를 무단 승격·조작하지 않는다.

## 롤백
- 기존 Quant 대시보드의 마지막 통합 커밋 전으로 해당 UI 관련 파일만 롤백한 후 8082 프로세스만 교체.
- OAuth/MCP/nginx/원본 연구 데이터에는 롤백할 변경이 없다.
