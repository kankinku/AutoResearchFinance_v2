# S6 2차 — 라이선스·버전이 추적되는 외부 계산 참조 검증

기준 2026-10-14. **새로운 수익 전략이나 실거래 주문 기능이 아니라, S6 기초 지표의 외부 계산 재현성·출처 검증**을 강화하는 단계. 기존 Quant Autoresearch의 URL, OAuth 데이터, 기존 연구 원장, 세대 해시 및 복구 기준점은 변경하지 않는다.

## 검증에 사용한 오픈소스

- **pandas**, 공식 프로젝트 <https://github.com/pandas-dev/pandas>, **BSD-3-Clause**. 테스트한 설치 버전: **3.0.6**. 이미 기존 QuantAutoResearch 의존성에 들어 있는 `pandas>=2.0`을 사용하므로 새 라이브러리를 설치하지 않는다.
- 참조 알고리즘은 공개 pandas API의 `Series.rolling(...).mean()`, `rolling(...).min().shift(1)`, `Series.ewm(..., adjust=False).mean()`이다. 외부 원본 코드/이름표를 복사하여 포함하거나 런타임에서 임의 패키지·Python을 실행하지 않는다.
- 자체 S6 계산기를 연구 엔진에서 그대로 사용하며, pandas는 **허용된 지표가 최초 검증될 때만** 수학적 비교를 위한 보조 계산 기준이다. 외부 라이브러리를 실시간 매매 승인이나 수익 예측으로 사용하지 않는다.

## 검증 경계

- 허용된 **정확히 네 가지** S6 이진 투표 신호만 비교한다: `sma_pullback_20`, `dual_sma_trend_50`, `ema_direction_20`, `range_low_reclaim_20`.
- 530봉 합성 추세/횡보/등락의 **3개 가격 시나리오**에서 각 봉별 전체 신호를 비교한다. 신호의 인과적 접두사·데이터 워밍업·이진(0/1) 값 유효성 검사. 검증받지 않은 신호 ID, 변조된 수식/필드, 지원하지 않는 pandas major 버전은 즉시 거부한다.
- **유사 경계값**: 이중 SMA의 두 평균이 사실상 같은 가격에서, pandas의 보정된 rolling 산술과 자체 `statistics.fmean`이 부동소수점 최하위 자리에서 달라 `>`의 참/거짓이 엇갈릴 수 있다. 차이가 기준 가격 대비 1e-12 이내인 경우만 **별도 borderline count**로 명시하고 더 큰 차이는 통과시키지 않는다. 이것은 완전한 바이너리 일치나 전략 재현성을 보증한다는 뜻이 아니다. 이미 S6-v1에 고정된 계산기/과거 신호를 바꾸지 않기 위한 연구 경계다.
- 각 지표별 외부 검증 기록에는 후보 정의 해시, pandas 버전, BSD-3-Clause 출처, 시험한 세 가지 시나리오, 경계 불일치 건수와 계산 결과 체크섬을 남긴다. `s6_external_provenance` 테이블은 중복 입력 시 동일하면 무변경 반환, 위조 또는 상충하는 데이터는 거부한다.
- `PROPOSED` → `VERIFIED`는 기존 독립 수학 검증과 외부 pandas 참조 검증 **둘 다 성공해야** 가능하다. 기존 학술 논문의 유의성/수익성을 승인하는 검사는 아니다.

## 버전별 연구 격리

- 기존 세션 `s3-v1`: `catalog.sqlite` 불변.
- 기존 세션 `s6-v1`: `catalog-s6-v1.sqlite` 불변. 이미 완료한 세대와 기존 거래 신호, 데이터 해시를 다시 계산하지 않는다.
- **새로운 세션 `s6-v2`**: 별도 `catalog-s6-v2.sqlite` 사용. 기존 S6 1차의 4개 지표 + 기존 코어 지표를 똑같이 제공하면서 외부 pandas 검증 이력을 추가. 세션 생성 시 pandas가 기록된 버전과 다르면 거부하고 **향후 버전 전환은 새 카탈로그 버전에서 수행**. 기존 `s6-v2` 세션의 조회는 프로바이더 업그레이드 후에도 기존 기록으로 가능하도록 새 연구 개시와 분리한다.
- MPC 도구 목록과 URL은 변경하지 않는다. 카탈로그 변경 내용은 기존 `start_algorithm_research`의 `model_context.verified_indicators` 및 `catalog_version`에 반영된다.
