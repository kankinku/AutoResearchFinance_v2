# Track 2 — 특수 시장 상황 조기탐지 · V3
기준점: quant-v3.0.0, c6fe2d7d70e34903110d889a718a9e80276e780a. 상태: 이벤트 탐지 신규 연구 트랙 정의, 실행/학습/모형 선정 미착수.

## 목표 (Q05/Q07/Q09/Q10/Q12/Q14/Q18/Q20)
폭락 위험, 급반등, 변동성 폭증 및 전환 이벤트를 미래 정보를 누설하지 않는 시점 기준으로 사전 탐지한다. 수익률 최적화와 다른 문제로, 탐지 precision, recall, precision-recall AUC, 오경보/연, 평균·중앙 lead-time, 사전 확률 보정(Brier/calibration)을 기록한다. 탐지 모델의 성공률만으로 투자 수익성을 주장하지 않는다.

## 작업 범위
T2-01. 사건 정의 계약: 관측 기준일 t, 이후 N 거래일의 drawdown/변동성/반등과 사전 경고 윈도, 이벤트 발생 중복 제거, 사후 알 수 있는 극값을 입력에 쓰지 않는 명세. 5/10/20% 또는 5/10/20거래일은 분석 후보이며 확정된 사용자 임계값이 아님.
T2-02. 빈도 기반 기초 모델과 레짐/추세/변동성 지표를 비교. 누적 2020~2025 QQQ 1개 종목의 폭락 이벤트 수가 적으므로 추가 장기 역사·자산 검토. 등록 지표 외 사후 수정 지표와 미검증 외부 데이터 직접 사용 불가.
T2-03. 희귀 사건 중심 PR-AUC, Precision@warning budget, Recall@lead-days, false alarms/year, event-level 분할 및 누출 방지 purged walk-forward 검증. 연속 폭락 날짜를 독립 사건 여러 개로 과대 계산하지 않는다.
T2-04. 1개의 알람에 해당되는 시점/사유/특징/검증 근거를 포함한 불변 예측 원장과 Champion 후보. Track1 신호 입력으로 사용하려면 별도의 as-of/PIT 검증 및 승인 필요.

## 수락 기준
- 각 경고의 시각 당시 알려진 데이터만 사용. 예측과 사건 정의 레이블 시간 분리.
- 희귀 사건에서 무경고/항상 경고 베이스라인과 공정 비교, 오경보 단위 및 비용 명시.
- 실패 모델·훈련 추정치도 보존하되 Track3 독립 시험 구간에 대한 학습이나 임계값 적합 금지.
- Quant 기존 주문/세대/G150 원장과 관련 OAuth/MCP 동작 무변경.

## 첫 번째 실제 구현 작업
이벤트 레이블 계약 및 사전 탐지 지표/기저빈도 감사. 신규 실험이나 외부 데이터 취득은 이 초기화 요청에 포함되지 않음.
