### 실제 소스 확인 기반 사전 발견(전수조사 완료 판정 아님)

- `core/features/chart_patterns.py`에 12개 이름이 있고, `core/features/catalog.py`의 `chart_*` FeatureSpec 및 `core/features/calculators.py`의 `chart_geometry` 분기가 존재.
- `impulse_five`는 6개 전환점을 한 번에 받아 **완성된 5파**만 판정. 1~4파 진행중 가설, 대안 카운트, 확장·절단·대각삼각형은 미지원.
- `abc_three`와 `complex_correction`은 개별 구간 ABC zigzag형과 3/5개 구성 조합에 한정. 엘리엇의 flat, triangle, combination과 정확히 같다고 부를 수 없음.
- `harmonic_xabcd`는 4개 패턴에 일부 비율과 고정 허용오차 0.09를 적용. XABCD 교차비율 전수, PRZ 겹침, 상호 배타성과 치명적 위반 사유 추적이 미흡.
- `classical_shape`는 더블톱·헤드앤숄더 등의 **형태 후보**만 평가하며 neckline 돌파 확정·거짓 돌파·무효화 조건과 구분하지 않음.
- 피벗은 좌우 `confirmation_bars=2`로 확인하고 `known_at`은 필드로 있으나, `lookback=160`, `minimum_swing=0.015`가 대부분 유형에 공통 적용됨. 스윙 탐색은 동률/일부 역전/결측의 영향이 있음.
- 출력이 +1/-1/0 이벤트 하나뿐이라 **후보 발견, 진행 단계, 확인, 무효화, 충돌하는 대안 카운트, 변동성 대비 크기, 유효 기간, 신뢰도**를 구분할 수 없음.
- 테스트 파일은 합성 지점 예시 + prefix 검사를 정의했지만 GitHub에 올라간 정확한 통합 HEAD의 **pytest/Ruff/mypy/시장 데이터/replay CI 결과는 미확인**. Moon remote 실행 도구 오류부터 복구해야 함.

### A2. 원본 문헌·오픈소스 수식·중복·라이선스 전수조사 (P0)

**대상 후보 표준:** 하모닉 ABCD·가틀리·배트·대안 배트·버터플라이·크랩·딥크랩·샤크·사이퍼·5-0 등, 엘리엇 임펄스·leading/ending diagonal·zigzag·flat(regular/expanded/running)·triangle·WXY/WXYXZ, 이중천장/바닥·헤드앤숄더·삼각수렴·쐐기·깃발·페넌트·채널/컵 핸들 등.

**절차:**
1. 원전·검증 가능한 공개 수식·공개 코드(라이선스 MIT/BSD/Apache 등)의 실제 구현 비교. '이름이 있다'는 것만으로 검증 인정하지 않음.
2. XABCD 모든 관련 다리 비율 정의, 위반 시 자동 탈락, 무효화/PRZ/발생조건을 **공식행렬(rule matrix)** 로 작성하고 한계와 서로 겹치는 계열을 기록.
3. 비상업/무라이선스 소스는 무단 코드 복제하지 않음; 참고 자료는 내용 출처를 보존하고 라이선스 승인이 필요한 것은 BLOCKED.
4. 이미 있는 지표와 (동일 수식/추가 출력/동일 계열 다른 구현/독립/미확정)으로 중복 및 계보 분류.
5. 후보 우선순위는 '이식 수량'이 아니라 **독립 정보량, 인과성, 계산 비용, 실제 연구 가능성**으로 결정.

**산출물:** 1) source SHA/license inventory, 2) ratio/formula matrix, 3) 후보별 중복 사유, 4) 구현 승인 shortlist.
**완료 조건:** 채택하는 모든 패턴에 명시 수식·단위 테스트 oracle·라이선스·결측/시차 규칙이 연결됨.

### A3. 시점 인과성·미래 데이터 누수 전수검사 (P0, 핵심 차단)

**대표 실패 유형:** ZigZag의 나중에 생긴 고점/저점을 과거 봉에 소급 표시; 확인에 필요한 N개 미래 봉을 숨기고 백테스트에 당일 신호로 사용; 완료되지 않은 ABC/5파를 완성으로 처리; 이후 넥라인 돌파를 예전에 이미 발생했다고 처리.

**검증 설계:**
- 개발 데이터 전 bar-by-bar 스트리밍 vs 완전 배열 prefix 재실행 결과 비교: 모든 t에서 동일한 **decision_at/known_at/feature_vector**.
- 이벤트가 실제로 관측 가능한 시각보다 빠르지 않아야 하며 **다음 봉 시가 체결**의 기존 룰 준수.
- 결측·불연속·동률·거래중단·분할/조정·일봉 종가 확정·동일 날짜 중복 데이터 경계 검증.
- 가짜 미래 가격만 바꿔 과거 신호가 달라지면 FAIL, 합성 상승/횡보/급락/초저유동성 레짐마다 테스트.
- **피벗 event time, confirmation time, decision time, order eligible time 분리**. 탐지 지연을 측정하고 그래프에 모두 표시.

**산출물:** prefix leakage gate, 사건 시간 감사 로그, 재도색률 0 조건 검사.
**완료 조건:** 재도색/미래누수 **0건** 확인. 하나라도 FAIL이면 StrategyIR 후보 차단.

### A4. 공통 피벗·스윙·패턴 인식 엔진 재설계 (P0)

**설계:**
- ZigZag/Fractal을 관측값 기반의 공통 `ConfirmedPivot` 프로토콜에 묶되, 기존 사용자 전략의 원본 feature 값은 변경하지 않고 **신규 버전**에서 분리.
- 스윙 크기 **ATR 대비·백분율·절대값**의 세 모드를 실험하되 룰이 고정되지 않는 연구 메타데이터 보존.
- 다중 크기(단·중·장기) 피벗, 동일봉 high/low 양극단, 연속 극단 갱신, 동률, 갭/결측, 초기 1~N 윈도우, 동일 시각 피벗 순위 정의.
- 탐지 가능한 후보 N개를 유지하면서 동일 피벗을 중복 카운트하지 않도록 pivot_id와 source hash 기록.
- 결과 구조: `candidate / developing / confirmed / invalidated`, 가격구간·스윙 비율·발생/확정 시각·근거 피벗·안전한 score, 필요하면 `unknown`.
- 즉시 동작할 `scalar` 별칭과 상세 구조 sidecar 분리. 여러 출력선이 독립 알고리즘 수를 부풀리지 않도록 family ID 보존.
- 긴 lookback의 메모리·CPU 제한, 캐시 시점 고정.

**산출물:** 인과형 피벗/패턴 공통 API·버전 규약·한계; 기존 12개 입력 호환 layer.
**완료 조건:** A3 인과성 PASS + 회귀 + 속도/메모리 예산 내 동작.

### A5. 하모닉 패턴 원식별기 개선 (P1)

- A2 수식행렬을 기준으로 X·A·B·C·D의 비율 `AB/XA`, `BC/AB`, `CD/BC`, `AD/XA`, 관련 XA 확장/ 되돌림과 방향을 모두 점검.
- butterfly, Gartley, Bat, Crab의 원본 4개를 우선 정합화. 후속 Alternate Bat, Deep Crab, Cypher, Shark, 5-0, AB=CD는 **A2에서 공식/라이선스 검증된 것만**.
- PRZ 진입, D 확정, 반전 확인, 무효화의 4단계로 신호 분리. 기본 +/-1로 바로 '매수/매도'하지 않고 단계/근거를 노출.
- 허용오차는 volatility-normalized/calibrated + pattern별 범위; 여러 패턴의 과도한 중첩은 탐지 충돌 로그로 처리.
- 유효/근접/무효/미확정 골든 XABCD 수치 사례 각 패턴별 확보.

**산출물:** 수식/PRZ oracle, 종류별 충돌 매트릭스.
**완료 조건:** source oracle과 수치·패턴 단계의 판정 일치, 미래 누수 없음, positive·negative test set 둘 다 통과.

### A6. 엘리엇 5파·ABC·복합조정 엔진 고도화 (P1)

- **1~5파:** 진행 중 파동 수(1~5), 2파 침범 금지, 3파 최단 금지, 4파 1파 가격 영역 교차 제한, 5파 종료·무효화·연장/절단 후보. diagonal 등 예외는 별도 명시 클래스.
- **ABC:** zigzag / flat / expanded flat / triangle 등은 각자 공식. A/B/C 추정 시점과 최종 확인 시점을 구별.
- **WXY / WXYXZ:** 복합 조정의 결합 구조를 중간 X파 역할까지 모델링. 기존 구현의 'ABC 단위 3·5개 단순 번갈음'을 전면적인 표준 파동 인식으로 오인 금지.
- 여러 가능한 카운트(beam search 또는 규칙 기반 다중 가설)를 제한된 상위 N개로 유지하고 서로 상충하는 카운트는 '확정 불가'로 유지.
- 피보나치 비율은 **근거·점수·무효화 임계치**로 사용하며 유일한 진실처럼 출력하지 않음. 목적 함수는 예측 적중률만이 아니라 실제 **사전확정 시점**과 신호 희소성/거짓 신호를 고려.

**산출물:** 5파 진행 엔진, ABC 다중 유형, WXY 구조 가설, 후보 목록/확정/무효화 예시.
**완료 조건:** 알려진 유효·무효 수치 fixture, prefix invariant, 대안 count 불확실성 처리, 0만 출력하는 기능 없음(실제 및 고안 시나리오에서 분리 확인).

### A7. 고전 패턴 실전 판정 강화 (P1)
