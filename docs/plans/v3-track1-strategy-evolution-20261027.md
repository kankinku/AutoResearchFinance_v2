# Track 1 — 기존 전략의 지속 발전 · V3
기준점: quant-v3.0.0, c6fe2d7d70e34903110d889a718a9e80276e780a. 상태: 계획/브랜치 초기화 완료, 신규 세대 실행은 아직 수행하지 않음.

## 목표 (Q02, Q05–Q10, Q14–Q18, Q20)
G150 완료 원장을 보존하면서 StrategyIR 부모 계승 + GPT 진단 + S7 반사실 실험을 발전시켜 거래비용 반영 성과를 개선한다. 기존 엔진·부모 메모리·해시 체인을 폐기하거나 새 연구를 G1로 다시 세지 않는다.

## 작업 범위
T1-01. G1–150 evidence/S7 부모 기억, 최근 반복 패턴 및 다중목표 frontier 읽기 전용 점검. G94 최고 수익/ G96·G60 저낙폭 등 부모 다양성 확인.
T1-02. 동일한 부모에 동일한 돌연변이를 재적용한 비효율을 제어하고, 무작위 탐색/계승/새 특징/국면 분기 비율을 증거에 근거하여 조정한다. 현재 엔진의 계보 승격·비용 평가·체결 재생 해시는 유지한다.
T1-03. 실제 사용자의 별도 세대 실행 요청이 있을 때만, 공식 150세대 다음 목표 연장을 안전한 토큰·원장 확장 절차로 실시. 계획→실제 비용 반영 백테스트→GPT 손실 원인 가설→S7 검증→증거 확정을 한 세대로 계수한다.
T1-04. 실험마다 QQQ 보유와 위험 보정 QQQ, MDD/Sharpe/거래 수, 신규 계보 비중, 과최적화 편향을 평가. 개발 데이터 내부에서만 수정 가능하며 Track3 봉인 데이터 접근 금지.
