# 백테스트 성과 중심 대시보드 구현 계획

## 범위

FastAPI `/backtest` 화면을 기존 원장 중심 UI에서 세대·성과 중심 UI로 변경한다. Paper-only 경계, 기존 API 라우트, 원장 데이터 형식은 유지한다.

## 단계

1. `BacktestResearchStatus`, `GenerationSummary`와 확장 KPI/추이 계약을 추가한다.
2. 원장과 자동 연구 상태를 세대별로 집계하는 순수 로직을 구현하고, 최고 후보 선택 규칙을 기존 화면과 일치시킨다.
3. 세대별 API 요약에 제안의 인디케이터 선택과 사유를 연결한다.
4. 대시보드를 현재 상태·KPI·성과 추이·세대 분석·접이식 진단 원장 순으로 재배치한다.
5. 브라우저 렌더링에서 수치, 연도별 안정성, lineage, gate, 검증 폴드, 빈 상태를 모두 표시한다.
6. API/정적 계약 테스트를 먼저 RED로 확인한 뒤 구현 후 GREEN으로 만들고, 전체 pytest·ruff·mypy·diff 검사를 수행한다.

## 완료 기준

- 현재/요청 세대와 단계 경과시간이 API 및 화면에 표시된다.
- 세대별 최고 후보의 전략 CAGR, QQQ CAGR, QQQ 대비, 점수, 위험 상태가 표시된다.
- 선택한 세대의 인디케이터·입력 자료·시간봉·lag/lookback·파라미터·제안 사유·연도별 결과가 표시된다.
- 실행 ID와 해시는 기본 목록에서 사라지고 접이식 진단 영역에서만 확인된다.
- 연구가 진행 중인 상태 파일을 15초 폴링으로 반영한다.
- 기존 Paper-only 및 API 보안 테스트가 유지된다.
