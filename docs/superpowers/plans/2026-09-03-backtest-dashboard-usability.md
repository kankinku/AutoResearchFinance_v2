# 백테스트 대시보드 사용자 탐색성 구현 계획

1. 기존 세대 요약 표에 검색·상태·성과 필터와 정렬 계약을 추가한다.
2. 최근 세대·최고 점수·QQQ 대비·위험 준수 빠른 선택 버튼을 추가한다.
3. 필터 결과 수, 현재 선택 세대, 결과 없음 안내를 일관된 한국어 UI로 연결한다.
4. 세대 선택기와 표·그래프·상세 분석이 같은 선택 상태를 공유하도록 정리한다.
5. 사용 설명을 접이식으로 추가하고, 기술 진단 영역은 기본 닫힘 상태를 유지한다.
6. 긴 그래프·세대 표·인디케이터 표·연도 표·원장은 내부 스크롤과 고정 헤더로 페이지 길이를 제한한다.
7. 정적 계약 및 API 회귀 테스트를 먼저 RED로 확인한 뒤 구현하고, 브라우저 화면·전체 pytest·ruff·mypy를 검증한다.
