# 백테스트 대시보드 사용자 탐색성 개선 설계

## 목표

사용자가 실행 ID를 해석하지 않아도 원하는 세대를 빠르게 찾고, 핵심 성과를 비교한 뒤 선택 후보의 전략 구성과 근거로 자연스럽게 내려갈 수 있게 한다.

## 화면 흐름

1. 상단에서 현재 연구 상태와 최고 후보 KPI를 확인한다.
2. `빠른 보기`에서 최근 세대, 최고 점수, QQQ 대비 우수, 위험 준수 세대를 즉시 선택한다.
3. 세대 탐색 도구에서 세대 번호·상태를 검색하고, 성과 기준으로 정렬한다.
4. 세대 표의 행이나 분석 선택 상자에서 한 세대를 선택한다.
5. 선택 세대의 성과·인디케이터·연도별 안정성을 본문에서 확인한다.
6. 실행 ID·해시·gate·검증 폴드는 필요한 경우에만 상세 진단을 연다.

## 사용성 원칙

- 기술 용어 대신 한국어 설명과 상태 색상을 사용한다.
- 검색 결과 개수와 활성 필터를 항상 표시한다.
- 성과 기준 정렬은 `전략 연복리`, `QQQ 대비`, `최고 점수`, `최근 세대`를 제공한다.
- 현재 분석 중인 세대는 표·선택기·상세 제목에서 동일하게 강조한다.
- 결과가 없을 때는 원인과 해제 방법을 함께 안내한다.
- 좁은 화면에서는 탐색 도구와 상세 정보를 세로로 쌓는다.
- 긴 세대·연도·원장 목록은 페이지를 늘리지 않고 독립 스크롤 표로 제공한다.
- 표 헤더와 그래프 영역은 고정 높이로 유지해 한 화면에서 다음 조작 지점을 계속 볼 수 있게 한다.

## 상태 경계

필터와 정렬은 이미 API로 받은 백테스트 원장에 대해 브라우저에서만 수행한다. 상태 파일과 주문 모듈에는 쓰지 않으며, Paper-only 안전 경계를 유지한다.
