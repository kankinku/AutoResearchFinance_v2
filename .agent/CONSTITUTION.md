# Quant — 프로젝트 헌법
1. /shared/AGENTS.md → 이 문서 → 프로젝트 AGENTS.md를 읽은 뒤 작업한다.
2. 작업 전 반드시 AGENTS.md에서 지정한 원래 20문항 계약, scope-lock, master progress ledger를 확인한다.
3. 사용자가 승인하지 않은 제품 변경/실거래 주문/보호된 백테스팅 엔진·검증 경로 변경 금지. 기존 AGENTS의 연구 단계 우선순위를 보존한다.
4. 프로젝트 코드·기록은 현재 브랜치/PR/원격 상태와 대조하고, 근거 없이 같은 연구를 다시 시작하지 않는다.
5. 검증과 Git 게시 상태를 실제 명령으로 확인하고 완료 여부를 정직하게 보고한다.
